## Dan 변경의 적용 위치

- `perception/spatial_features.py`, `ml/spatial_mlp.py`: 같은 96차원 특징과 모델 가중치 형식.
  MediaPipe 객체 입력도 받는다. 원본과 특징·MLP 확률의 동일성을 합성 입력으로 비교한다.
- `ml/spatial_hybrid.py`, `features/tcn_gate`: 0.42 혼합, 정지 자세의 빠른 확인 및 중립 거부,
  클래스별 확인 기준과 `disabled_gestures`를 이식한다. 명시적인 `tcn_gate.spatial_hybrid=true`와
  Spatial 모델이 있는 확인기 경로에서만 사용한다. 기본값은 false이며 직접 TCN 소유권을 바꾸지 않는다.
  손 소실·reset 때 Spatial 증거를 지우고 현재 프레임 증거만 빠른 확인에 사용한다.
- 학습은 현행 선택 분류기 보존·연속 TCN·별도 Spatial worker를 유지한다. Dan 스크립트처럼
  선택 학습 때 모든 Spatial 클래스를 자동 재학습하거나 무작위 인접 프레임을 평가로 세지 않는다.
- `tools/import_training.py`: TCN과 Spatial 모델을 보관함에 등록하고 새 개인 모델은 시험 상태로 연결한다.
  원본의 `thumbs_up` 확률은 보존하되 모드 전환을 직접 TCN 명령으로 만들지 않는다.
  비활성 클래스·클래스별 임계값도 보존한다. 단일 모델은 제외된 클래스 때문에 확률을 재정규화하지 않는다.
- 원본 ONNX의 Pad-18은 선택 결합에 필요한 opset 17로 검증해 변환한다. 기본 변환기가 실패하면
  axes 입력 없는 Pad만 스키마가 달라지는 그래프에 한해 호환성을 확인한다.
  그 밖의 연산 변경·하위 그래프는 거절하며 ONNX checker와 변환 전후 실제 추론 확률을 비교한다.

## 데이터 가져오기

원본 녹화·모델은 Git 밖에 보존한다. 허브의 구형 녹화는 해시가 일치하고 명시된 메타데이터가
충돌하지 않을 때만 빠진 별명·preset을 보충한다. 과거의 동작별 preset은 현행 제어 모드로
변환하고 원래 preset을 출처에 기록한다. 프레임·동작 라벨·명시된 train/eval은 바꾸지 않는다.
split이 없으면 train이며, 원격 목록만으로 eval을 만들지 않는다.
원본 SHA를 보존해 Dan 원본과 허브 파일의 중복 다운로드·업로드를 피한다.

기존 설정 파일이 있으면 저장하지 않은 현행 기본값도 사용자 설정으로 취급한다.
옛 설정의 누락 키를 덧씌우지 않는다. 이는 구형 주먹 이동 배율 등이 복원되며 감도가 바뀌는 일을 막는다.
사용자별 선택 값과 모델의 실제 활성 여부는 Git 파일 유무와 별도로 확인해야 한다.

## 클릭 판정 보완과 검증 한계

이미지에서는 중지/약지가 명확하게 닿는데 world 추정에서 검지가 가장 가까운 경우가 있다.
이때 이미지의 유일한 접촉과 world의 중지·약지·새끼 구분을 함께 확인한다.
world에서 명확한 접촉 대상이 있으면 그 판정을 유지하고, 새끼손가락 창 전환은 완화하지 않는다.
눌린 클릭의 해제·긴 누름 드래그·재무장 조건은 유지한다.

합성 회귀 시험과 기존 학습 녹화 재생은 독립적인 실사용 정확도 평가가 아니다.
가져온 모델은 별도 평가 없이 실제 입력 모델로 승격하지 않는다. 새 촬영 없이 보장할 수 없는
원거리·각도별 정확도와 휴대폰 실제 클릭 감각은 별도 검증 항목으로 남긴다.
