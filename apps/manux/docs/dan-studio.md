## 화면 열기

기존 Rasp-Jun 메인은 그대로 사용한다. 상단 **녹화·시뮬레이터**에서 새 작업 화면으로 이동한다.
공용 화면의 **학습 센터**에서도 같은 도구를 쓴다. 원본의 학습 진행·방향 보정·설정·집중 녹화는 유지한다.

```powershell
cd apps/manux
uv run --locked --python 3.12 --extra ui --extra vision --extra ml --extra train --extra hub python -m manux --ui studio
```

`--ui standard`는 공용 메인 화면이다. 마지막 UI 선택은 현재 testing 구현대로 보존한다.
학습센터에서 선택한 동작의 **집중 녹화 설정**을 열거나 여러 동작을 체크하고 하단에서 시작한다.
상단 **학습 진행**으로 현재/이전 작업의 진행률·손실·ETA를 확인한다.

## 녹화에서 학습까지

1. 내 별명으로 학습용과 별도 평가용을 **다른 시도**로 녹화한다. 팀 기록은 모델·공유에서 받는다.
2. 녹화 목록에서 파일을 선택해 재생한다. 품질 경고를 누르면 해당 시점으로 이동한다.
3. 필요한 train 파일만 포함한다. 평가는 완료된 별도 원본 시도를 모두 사용한다.
4. 보정·증강은 원본 train에만 만든다. 생성 직후는 제외 상태다. 직접 검수한 뒤 포함한다.
   선택한 보정본은 해당 원본을 대체하고 증강본은 train에 추가한다. 수집 진척 횟수에는 더하지 않는다.
5. 동작을 체크하고 선택 학습한다. 기존 다른 분류기의 가중치는 유지하며, 기존 클래스의 eval은 필요하다.
6. 설치 후 시뮬레이터에서 현재 정책과 TCN 연습 적용 이벤트를 비교한다. 충분히 확인한 동작만 적용한다.

변환본 meta.lineage의 원본 해시도 모델 카드에 기록한다. 원본 계보가 겹치는 eval은 설치에서 거부한다.
관절 보간은 파생본에만 기록하고 2D로부터 world를 합성하지 않는다. 파생본·휴지통은 HF 공유에서 제외한다.

## 차이와 검증 한계

- Dan의 개별 파일 삭제/카드 편집에 의한 초기화 대신 검증 후 불변 버전 복원을 사용한다.
- 재생은 녹화 해상도 비율을 유지하며 손 21점을 손가락별 색으로 표시한다. 팔·어깨는 버튼으로
  켰을 때 기록된 점만 표시한다. 최근 측정 pose의 시각을 표시하고 0.3초를 넘기면 사용하지 않는다.
  pose는 TCN 특징으로 사용하지 않는다. 손이 없는 구간은 그대로 알리며 `다음 손 프레임`으로
  실제 측정된 구간을 찾는다. 0.5×/1×/2× 재생은 원본 시각과 단조 시계를 사용한다.
  작은 손은 `손 확대` → `4배 확대`로 확인하고, 화면 내 위치는 `전체 보기`로 돌아와 확인한다.
  확대는 기록된 손 중심을 따라가며 재생 표시만 바꾼다.
- 품질 점수는 올바른 손짓이나 라벨임을 보증하지 않는다. 잘못된 경고로 올바른 시도를 자동 제외하지 않는다.
- 시뮬레이션은 현재 코드와 저장 설정의 비교이며 실사용 정확도나 카메라·OS 지연 측정이 아니다.
- 새 Windows 설치본·실제 웹캠·실제 OS 입력·다인 평가 결과는 별도다. testing 검증이 preview/production
  릴리스를 대신하지 않는다. 정식 전달은 원본 제품 변경의 preview PR로 진행한다.
