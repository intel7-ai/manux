# v0.5 처음 사용하기와 연습 화면

## 시작 순서

1. 사용할 손을 정한 뒤 카메라에서 관절 21점과 뼈대가 손을 따라오는지 확인합니다. 조작 손이 1초 연속 보이면 다음 단계로 넘어갑니다.
2. 기본 속도·빠른 이동 가속을 맞춥니다. 편 손으로 빠르게 이동하고 주먹으로 느리게 정밀 이동합니다. 화면의 가상 커서로 목표 3개를 손짓 클릭하고, 손바닥 모드에서는 주먹 정밀 이동도 한 번 확인합니다. 검지 포인터에서는 주먹 확인을 요구하지 않습니다. 클릭을 꺼 둔 포인터 설정은 목표 클릭 대신 이동 연습을 합니다.
3. 클릭을 한 번 확인합니다. 선택한 입력 방식에 맞는 손가락 안내를 따릅니다.
4. 스크롤을 확인합니다. 스크롤이 없는 입력 방식은 이 단계를 표시하지 않습니다.
5. V를 0.7초 유지하고 손을 편 상태로 돌아옵니다. 1.5초 뒤 다시 V를 해 켜기·끄기를 두 번 확인합니다. 이 단계에서는 실제 PC 제어 상태를 바꾸지 않습니다.
6. 모션 모드는 선택 단계입니다. 자주 쓰지 않으면 바로 건너뛸 수 있습니다. 동작 목록의 기능을 삭제하거나 기본값을 끄는 결정과는 별개입니다.

연습은 `practice` 출력만 사용합니다. 실제 Windows 커서·버튼·키는 보내지 않습니다. 연습 커서는 실제 출력과 같은 커서 매핑 계산을 사용하며 OS 입력 없이 화면 목표만 클릭합니다. 감도를 적용하면 기존 출력과 판정 상태를 안전하게 해제합니다. 메인 화면에서 제어를 다시 켜야 실제 입력을 시작합니다.

성공은 엔진이 받아들인 동작으로만 확인하며 거절·오류는 성공으로 세지 않습니다. 각 성공 뒤 1.2초 동안 결과를 보여주고 다음으로 이동합니다. 각 단계 시작·이전·재시도·넘어가기에서 연습 출력과 기능 상태를 초기화하고 기본 모드로 돌아갑니다.

15초 동안 단계를 끝내지 못하면 안내 시도를 하나 기록합니다. 3회 뒤에는 이유 안내와 재시도·이 단계 건너뛰기를 제공합니다. 이 횟수는 시간 내 완료 여부이며 모델 인식 실패율을 측정한 값이 아닙니다. 건너뛴 단계는 성공으로 표시하지 않습니다. 모든 단계에서 나중에 배우기로 종료할 수 있고, 메인 화면의 동작 다시 배우기로 돌아올 수 있습니다.

## 학습 센터 첫 사용

녹화 탭은 시간에 따른 손동작을 학습하고 별도 시도로 평가하는 곳입니다. 포즈 표본 탭은 한 자세의 관절 표본을 모아 모양 모델을 만드는 곳입니다. 평가용 녹화를 포즈 표본으로 대체하지 않습니다.

녹화는 별명 저장 → 동작 체크 → 집중 녹화 설정 → 별도 평가 녹화 → 검증 후 적용 순서로 안내합니다. 포즈 표본은 자세 선택 → 카메라 관절·정답 이름 확인 → 표본 수집 → 표본 저장과 학습 → 새 시도로 결과 비교의 다섯 단계를 표시합니다. 연속 프레임 수를 독립 시도 수로 세지 않으며 모델 학습만으로 실제 제어를 자동 적용하지 않습니다.

## 수정 근거와 확인 범위

2026-11-07 피드백은 기존 바탕화면 단계 이후 인식이 멎었다는 보고였습니다. 소스에서 확인한 별도 결함은 스튜디오 레이아웃에 연습 화면 자체가 없고 `stage != main` 패널이 tutorial 단계에도 손 설정 문구를 표시한다는 점입니다. 두 레이아웃에서 같은 `TutorialPage.qml`을 사용하도록 연결했습니다. 기존 연습 상태는 단계 전환 시 이전 액션·시각과 엔진 모드를 유지했으므로 단계별 초기화도 추가했습니다. 바탕화면 기능은 메인 목록에 유지하며 일상 제어 중심의 연습 순서에서는 제외했습니다.

합성 엔진 이벤트·목표 클릭·시간 경과와 Qt 렌더링으로 검사합니다. 실제 웹캠에서 보고된 멈춤 현상의 완전 재현과 새 손동작 사용성 확인은 별도 수동 시험이 필요합니다. 이 문서는 실제 손 인식률이나 편의성이 검증됐다는 뜻이 아닙니다.
