## 실행과 상태

현재 앱은 기존과 같이 실행한다.

```powershell
cd apps/manux
uv run --locked --python 3.12 --extra ui --extra vision --extra ml --extra train --extra hub python -m manux
```

**Git 이력을 합친 상태이며 Dan의 새 탭이 v0.4 화면에 연결됐다는 뜻은 아니다.** 현재 앱은
preview의 검증된 실행 경로를 유지한다. Dan 소스는 기본 패키지·설치본에 포함하지 않는다.
Dan의 개인 ONNX·녹화·실패 로그·인증·로컬 프로필·원본 기반 fixture도 새 트리에 복사하지 않았다.
누락된 모델이나 자료가 필요한 원본 실행·시험은 그대로 성공한다고 주장하지 않는다.

## 실제 기능 이식 때 해결할 계약

1. 현재의 선택 학습은 기존 클래스를 유지하는 통합 재학습이다. Dan의 독립 이진 모델 bank와
   개별 초기화 후 규칙 복귀를 그대로 연결하면 현재 모델 검증·거절 우회 금지 계약과 달라진다.
2. 보정본·증강본은 원본 시도 계보를 기록하고 train/eval 독립성을 지켜야 한다. 같은 시도의
   변형본을 새 독립 평가 시도로 세지 않는다. 원본은 보존한다.
3. 2D 관절에서 합성한 world 좌표와 추정 팔/어깨를 실제 측정 데이터로 취급하지 않는다.
4. 시뮬레이터는 실제 런타임의 연속 확정·중립 복귀·모드·바인딩을 재현하고 OS 입력은 내지 않는다.
   단일 프레임 확률만으로 실행 적중률을 주장하지 않는다.
5. 이식은 v0.4의 data/tracking/ml/UI/worker 경계로 나눈다. 새 Pose 추적의 처리 비용을 측정하고
   #76의 한 손 기본값·프레임 누적 금지·출력 해제 계약을 보존한다.

preview로 보낼 제품 PR은 이 이식과 새 UI·안전 회귀 검증이 끝난 뒤 별도로 만든다.
