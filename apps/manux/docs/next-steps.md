# 다음 작업

## 현재 작업 순서 (preview `5f2c12b` + PR #72 통합)

이 절은 과거 최초 계획과 구분한 2026-11-06 상태 보충이다. 기준 preview에는 #69 직접 TCN·모델 수명주기, #70 Preview 설치본·트래킹 측정, #68 허브 CLI가 병합됐다. 구현 계약은 [계약](contracts.md), 사용법은 [직접 TCN](direct-tcn.md)·[허브](dataset-hub.md)를 따른다. 아래 항목은 팀의 기존 결정 상태나 제품 출시 기준을 새로 승인하는 것이 아니다.

1. **학습 센터 통합:** [PR #72](https://github.com/intel7-ai/manux/pull/72)의 체크 목록·선택 녹화·통합 재학습·별도 eval 검증·HF 공유·별도 worker를 연결한다([사용법](learning-center.md)). `.env` 인증은 worker만 읽고 앱에는 별명만 저장한다. 후속 #75 입력·권한 표시와 #76 추적 지연 수정을 순서대로 통합하고 실제 웹캠·Windows 입력·실패 복구 결과를 수집한다.
2. **독립 데이터 수집:** 팀원별 train/eval을 별도 시도로 수행하고 `tools/hub.py`로 공유한다. 규칙·확인기·직접 판정의 적중·오실행·지연을 같은 독립 입력으로 비교한다. 프레임 수를 독립 사용자 시도 수로 쓰지 않는다.
3. **남은 개발:** 사용자 정의 카탈로그·바인딩 편집 화면·미리보기 그리기·v0.3 중첩 설정 변환과 실제 사용에서 확인된 문제를 작업 단위로 다룬다. 이미 병합된 §4.4 기능을 다시 만들지 않는다.
4. **가속은 후속 측정:** [PR #73](https://github.com/intel7-ai/manux/pull/73)은 가속·데이터 품질·정리 조사 제안이며 구현이 아니다. 학습 시간의 구간별 측정 뒤 CUDA 등 장치별 실험을 선택한다. NPU 추론과 GPU 학습을 구분한다.
5. **정식 배포 전환:** 실제 PC에서 Preview 설치본의 기능·입력 해제·복구를 확인한 뒤 v0.4 릴리스 workflow 연결을 별도 PR로 진행한다. 그전까지 Releases는 v0.3에서 빌드한다. Preview 빌드 성공만으로 S3/S6 수동 확인이나 정식 전환을 완료 처리하지 않는다.
