# 결정 기록 (apps/manux)

결정 하나에 한 절. 상태는 **확정**(사람이 결정함) / **제안**(팀 검토 전) / **대체됨**. 결정을 바꿀 때는 지우지 않고 새 절을 추가하고 이전 절을 "대체됨"으로 표시한다. 에이전트는 **제안** 상태를 확정된 규칙처럼 설명하지 않는다.

## D-001 UI 플랫폼: Qt/QML + Python 한 프로세스

- 상태: **확정** (2026-11-05, Sean Choi)
- 배경: 저장소에 화면이 세 종류 있다. Qt/QML(`hand-mouse/`, 설치·자동 업데이트 중), Electron(`desktop/`), Electron UI + Python 엔진 프로세스(`codex/touch-desktop-rebuild`). 엔진은 어느 경우든 Python이다(MediaPipe, TCN 학습(PyTorch), ONNX).
- 결정: v0.4는 Qt/QML + Python 한 프로세스로 만든다.
- 이유: PyInstaller + Velopack 설치·업데이트 경로가 이미 동작한다. 런타임과 빌드가 하나다. 손가락 HUD 오버레이가 이미 Qt에 있다.
- 결과: 엔진은 Qt를 import하지 않는다(구조 시험으로 강제). 나중에 화면을 바꿀 수 있도록 UI는 Snapshot·UiCommand 계약만 쓴다. Electron 쪽 기능 개발은 v0.4 범위 밖이다.
- 고려한 대안: Electron UI + Python 엔진(프로세스 경계로 계약이 강제되고 웹 기술을 쓸 수 있으나 런타임·설치 체인이 둘), Tauri(새 언어·도구 추가).

## D-002 새 앱 위치: `apps/manux/`, `hand-mouse/`는 수정만

- 상태: **확정** (2026-11-05, Sean Choi)
- 결정: v0.4는 `apps/manux/`에 새 구조로 만든다. `hand-mouse/`는 v0.4가 기능 목록을 대체할 때까지 설치본으로 유지하고 버그 수정·데이터 수집만 받는다.
- 결과: v0.3 코드는 모듈 단위로 옮기고, 옮길 때마다 재생 비교로 같은 출력을 확인한다([구조 §8](architecture.md#8-이식-순서)). 같은 기능을 두 곳에서 동시에 새로 개발하지 않는다. `hand-mouse/`에 들어간 수정은 PR 본문에 v0.4 반영 여부를 적는다.

## D-003 기능 모듈과 조립 지점 하나

- 상태: **제안**
- 결정: 기능은 `features/<id>/`에 하나씩 두고 서로 import하지 않는다. 모든 연결은 `app.py`에서 한다. 기능 사이의 상호작용(예: 핀치 중에는 모션 진입 금지)은 중재기가 `activity()`를 보고 정한다.
- 이유: v0.3에서 모션 모드가 다른 엔진의 비공개 필드를 읽어 결합이 생겼다.

## D-004 동작 ID와 액션 ID 분리

- 상태: **제안** (기존 AGENTS.md 기술 경계를 v0.4에 적용)
- 결정: 기능은 동작 ID(`pinch.thumb_middle`)만 낸다. 무엇을 실행할지는 바인딩(`pinch.thumb_middle → mouse.left_click`)이 정한다. 바인딩이 없는 동작은 아무것도 실행하지 않고 기록만 남긴다.

## D-005 모델 배포 기준

- 상태: **제안**
- 결정: 학습 모델은 모델 정보 파일([계약 §10](contracts.md#10-모델-파일))이 있어야 읽는다. 특징 버전이 맞지 않거나 파일이 없으면 그 기능을 끄고 화면에 이유를 보인다. 새 모델은 학습에 쓰지 않은 사람 또는 자세의 평가에서 규칙보다 나쁘지 않을 때만 기본 모델로 바꾼다.
- 이유: 현재 TCN 성적은 한 사람·한 세션·한 카메라 기록이다.

## D-006 학습 데이터 위치

- 상태: **제안** (Dan 확인 필요)
- 결정: 개인 녹화 원본(`*.jsonl.gz`)은 공개 저장소에 두지 않는다. 시험에는 동의받은 짧은 익명 구간이나 합성 기록만 쓴다. 원본 보관 위치(비공개 저장소 등)는 팀이 정한다.
- 배경: Dan 브랜치에 10 MB 녹화가 있다. PC·사용자 이름은 지웠지만 한 사람의 손 움직임 기록이다. 저장소 규칙은 개인 프로필을 저장소에 넣지 않는 것이다.
