# testing 통합 앱: 녹화부터 모델 선택까지

2026-11-06. 현재 v0.4 작업을 통합한 소스 시험 경로다. 정식 설치본이나 production 릴리스가 아니다.

## 실행

저장소 루트의 `run_manux.bat`를 실행한다. Python 3.12와 `uv`가 필요하며 처음에는 UI·카메라·학습
의존성을 내려받는다. 이미 실행 중인 MANUX는 종료한 뒤 실행한다. 소스 checkout들은 기본 사용자
데이터를 공유하므로 동시에 실행하지 않는다. CUDA를 설치한 별도 Python은 다시 `uv sync`하지 말고
[가속 안내](hardware-acceleration.md)의 명시적 Python으로 실행한다.

```powershell
cd apps/manux
uv run --locked --python 3.12 --extra ui --extra vision --extra ml --extra train --extra hub python -m manux --ui studio
```

두 메인(`studio`, `standard`)의 **학습 센터**는 같은 화면이다. 민트·네이비 색, 한글 글꼴, 선택 상태,
고정 실행 바를 공유한다. Rasp-Jun의 메인·자세별 녹화 계획·진행/ETA·손실·모니터 전환·손바닥 보정은
보존했다. 센터를 열면 실제 PC 제어가 멈추며, 닫은 뒤 제어를 직접 다시 켠다.

## 오늘 시험할 사용 흐름

1. 카메라에 손을 보여 조작 손과 안내를 완료한다. 학습 센터 상단에서 익명 별명을 저장한다.
2. **동작**에서 체크한 항목이 녹화·선택 학습 대상이다. 행을 눌러 자세 안내를 보고 집중 녹화
   조건을 조절한다. **선택 동작 녹화**로 계획을 시작한다. 다른 분류기는 그대로 보존한다.
3. **학습용**과 **별도 평가**는 서로 다른 시도로 녹화한다. 같은 시도를 복사해 eval로 쓰지 않는다.
   학습이 끝나도 새 분류기는 시험 상태다. 동작별 `규칙 / 시험 / 적용`에서 실제 적용을 선택한다.
4. **녹화**에서 관절·이벤트를 재생하고 학습 포함 여부를 고른다. 보정·증강은 원본을 보존하며,
   파생본은 검수 후 직접 포함해야 한다. 휴지통은 되돌릴 수 있는 로컬 이동이다.
5. **데이터 공유**에서 연결·쓰기 권한을 확인한다. 체크한 동작에 해당하는 내 별명의 완료 원본만
   업로드한다. 여러 동작을 담은 녹화는 파일 전체가 공유된다. 다운로드도 체크한 동작으로 필터한다.
   체크하지 않으면 전체 동작이다. train/eval과 해시를 보존하며 기존 파일을 덮어쓰지 않는다.
6. **모델**에서 이름을 정하고 업로드한다. **공유 모델 불러오기 → 다운로드 → 이 모델로 시험**으로
   후보를 비교한다. 다운로드는 active를 바꾸지 않고, TCN 시험은 강제 shadow다.
   **검증 후 이 모델 사용**과 **검증 후 복원**은 현재 별명의 전체 별도 eval을 다시 검사한다.
   부족·회귀·취소면 이전 active를 유지한다. 같은 표시 이름의 모델도 해시로 구분한다.
7. **시뮬레이터**는 실제 엔진·바인딩·현재 정책과 연습용 전체 TCN 적용을 비교한다. Windows 입력을
   내지 않는다. 모델 단일 프레임의 argmax 비율을 실제 명령 성공률로 표시하지 않는다.

## 빠른 포즈 표본

**포즈 표본**은 Park의 현재 v0.4 96차원 Spatial MLP 경로다. 열 자세 중 하나를 고르고 한 장씩
또는 연속 수집한다. 불일치만 모으는 옵션도 있다. 상단 train/eval은 처음 표본을 모을 때 고정되며
용도·별명을 바꾸려면 저장하고 **새 수집**을 누른다. eval 파일은 MLP 학습에서 제외한다.

포즈 모델 학습은 별도 worker에서 실행한다. 완료 모델은 보관함에서 이름을 붙여 공유할 수 있다.
포즈 모델을 선택하면 스튜디오 미리보기만 바뀌며, TCN의 active와 동작별 정책은 바뀌지 않는다.
표본 업로드·다운로드는 현재 고른 포즈에 한정한다. 원시 영상은 저장하거나 공유하지 않는다.

프레임 단위 내부 점수는 독립 사용자 평가가 아니다. 보조 차단은 기본 꺼짐이다. **실험 보조 차단**을
직접 켜면 기존 명령을 거부하는 데만 쓰며 새 명령을 만들거나 TCN 거절을 우회하지 않는다.
모델/차단 변경과 출력 해제는 엔진 프레임 경계에서 처리한다. 다른 TCN 확인기와 직접 TCN을 함께
쓰는 것은 계속 금지한다. Spatial MLP를 TCN의 ONNX 가속 경로로 설명하지 않는다.

## 인증과 저장

`apps/manux/.env.example`을 `.env`로 복사해 설정한다. 앱에 토큰 입력란은 없다. 기본은 HF이며
선택적으로 `MANUX_HUB_PROVIDER=github`, `MANUX_GH_REPO`, `MANUX_GH_BRANCH`, `MANUX_GH_TOKEN`을 쓴다.
GitHub 저장소는 먼저 만들어 두어야 한다. GitHub 공유는 파일·인덱스를 한 비강제 커밋으로 반영하고,
동시 변경 충돌을 순차 업로드로 우회하지 않는다. 90MiB 이상 파일은 HF를 사용한다.

모델 보관함은 사용자 데이터의 `models/library/<내용 ID>`다. 원격 이름은 파일 경로로 쓰지 않는다.
ONNX·카드의 해시, 특징·차원, 외부 가중치 참조를 검사한다. 공유 포즈 파일은 허용된 좌표·라벨 필드만
내보낸다. 다운로드한 포즈 표본은 `pose_snapshots/received`에 두며 모델·설정·원본 녹화를 덮어쓰지 않는다.

## 확인한 범위와 다음 실제 시험

실제 PC에서 카메라 `1280×720 · 30fps`, 배경 포즈 worker 완료, QML 오류 0을 확인했다.
8.5초 시험에서 카메라 프레임 79개를 관측했다. Qt 16ms 타이머 간격의 중앙값 15.61ms/p95 20.25ms,
앱 프레임 경과 중앙값 17.09ms, 손 추적 처리 중앙값 12.48ms였다. 타이머 간격은 디스플레이 FPS가
아니며, 프레임 경과는 센서부터 OS·화면까지의 지연이 아니다. Windows 입력과 원시 영상 저장은 껐다.
합성 표본으로 배경 학습했으며 실제 손짓 정확도나 다인 평가를 측정한 결과는 아니다.

이 PC의 기존 `.env`에서 HF 읽기·쓰기 권한과 인덱스 19개를 확인했다(원격 변경 없음).
실제 업로드/다운로드는 각 PC의 `.env`로 먼저 소량 확인한다. 오프라인 모의 허브의
모델·데이터 왕복 성공을 실제 팀 저장소 업로드 성공으로 표현하지 않는다. testing은 자동 CI·설치본
빌드를 하지 않으며 정식 전달은 원본 preview PR과 별도 검증을 거친다.
