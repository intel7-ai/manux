# 제스처 선택 학습

학습 센터의 각 동작 행에 있는 **이 동작만 학습**은 그 동작의 이진 TCN을 학습한다.
정답은 선택한 동작, 오답은 중립과 다른 동작의 유효한 녹화다.
좌클릭과 중지 유지 드래그는 같은 학습 클래스를 공유한다. 이동·중립은 모든 동작의
오답 자료로 사용한다. 조건 하나를 제외한 평가는 별도로 기록하며 학습 정확도와 구분한다.

## 저장과 실행 계약

- 기존 통합 모델은 그대로 읽는다. 현재 통합된 학습 경로는 `models/selected/<실행 ID>/`에 새 모델과 정보 파일을
  쓰고, 학습·내보내기·추론·최소 구분 성능 검사를 마친 뒤 `gesture_tcn.selected.json`을 원자적으로 교체한다.
- 목록은 클래스별 파일을 가리킨다. 선택하지 않은 클래스의 파일 참조는 보존한다.
  게시 전 실패와 학습 중단은 기존 목록을 바꾸지 않는다. 학습 쓰기는 프로세스 잠금으로 직렬화한다.
- 이전 `models/gestures/manifest.json` 형식도 읽고 내보낸다. 같은 클래스가 양쪽에 있으면 현재 `selected` 목록이 우선한다.
- 실행기는 선택 모델의 점수를 해당 클래스에 우선 사용한다. 선택 모델의 거부는
  통합 모델의 같은 클래스 확률로 우회하지 않는다. 다른 클래스는 기존 판정을 유지한다.
- 새 모델은 시험 모드로 시작한다. 좌·우클릭의 기존 규칙 동작은 바로 전달하며, 동작별 적용·3D 클릭 보완과
  진행률·ETA·검증 기준은 [학습센터 안내](training-studio.md)를 따른다.
- 모델 갱신은 새 모델 묶음을 전부 읽고 검증한 뒤 교체한다. 실패하면 이전 판정기를 유지하고
  오류를 알린다. 판정기 교체 전에 눌린 입력과 상태를 해제한다.
- 모델 파일은 서로 독립된 확률을 반환한다. 합계가 1인 통합 분류 확률과 구분한다.
- 내보내기에는 manifest와 그 manifest가 참조하는 모델들을 함께 넣는다.

## 직접 실행

```powershell
.venv/Scripts/python.exe scripts/train_tcn.py --gestures thumb_middle --folds --epochs 25
```

`--gestures`는 `--tasks`와 같은 입력 옵션이다. 여러 키를 지정하면 선택한 클래스들을 함께 학습하고
그 클래스들의 경로만 교체한다. 각 행의 버튼은 한 클래스의 이진 모델을 만든다.
체크박스로 여러 동작을 선택하는 학습과 행별 단독 학습 모두 같은 검증·진행률 경로를 사용한다.
