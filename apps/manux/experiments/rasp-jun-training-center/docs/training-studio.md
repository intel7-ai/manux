# 손짓 학습 스튜디오 (2026-11-05)

이 앱은 이제 **TCN 학습 앱**이기도 하다. 틈날 때 녹화하고, 학습하고, 동작별 성적을 보고, 부족한 동작만 더 녹화하고, 다른 앱에 넣을 묶음으로 내보낸다.

```
녹화 → 학습 → 동작별 성적 확인 → 부족한 동작 집중 녹화 → 다시 학습 → 내보내기
```

## 1. 시작: `studio.bat` (긴 명령을 외우지 않아도 됨)

`studio.bat`을 두 번 클릭하면 번호 메뉴가 뜬다. 처음이면 uv와 라이브러리(`--extra qt --extra train`)를 자동으로 설치한다.

| 번호 | 하는 일 | 실제로 실행되는 명령 (`uv run --locked --extra qt --extra train` 뒤) |
|---|---|---|
| 1 | 앱 실행 (연결된 카메라, 번호를 물어봄) | `python main.py --ui qt --source N` |
| 2 | 앱 실행 (휴대폰 브라우저 카메라) | `python main.py --ui qt --phone-web` |
| 3 | 학습 센터 리포트 (콘솔) | `python scripts/training_report.py` |
| 4 | TCN 학습 | `python scripts/train_tcn.py --folds` |
| 5 | 모델 내보내기 | `python scripts/export_model.py` |
| 6 | 시험 돌리기 | `python -m pytest -q` |

메뉴는 고를 때마다 실제 명령과 그 뜻을 보여 준다. 옵션의 뜻:

| 옵션 | 효과 |
|---|---|
| `--extra qt` | Qt 화면(PySide6)을 설치·사용. 빼면 uv가 지운다 |
| `--extra train` | 학습·모델 실행(torch CPU, onnx, onnxruntime). 빼면 uv가 지운다 |
| `--locked` | `uv.lock`에 적힌 버전 그대로 (PC마다 같은 환경) |
| `--ui qt` | MANUX Qt 화면 (녹화·학습 센터·손짓 확인이 있는 화면) |
| `--source N` | 카메라 번호. 0 = 첫 카메라 (이 집 PC는 폰 카메라가 0) |
| `--phone-web` | 휴대폰 브라우저를 카메라로 (QR 접속) |
| `--headless` | 창 없이 알림 영역(트레이)에서만 |
| `--profile 이름` | 보정 프로필 고르기 |

`run.bat`은 예전처럼 바로 앱을 켠다(같은 라이브러리 묶음).

## 2. 앱 안의 "학습 센터" (위쪽 버튼)

동작마다 한 줄씩:

- **데이터**: 녹화한 반복 횟수 / 목표 30회, 녹화한 자세 수 / 3 (반주먹 이동은 분 / 목표 9분). 막대가 노란색이면 부족.
- **인식**: 학습에 **쓰지 않은** 자세에서 맞힌 비율 = 처음 보는 상황에서의 실력. 괄호는 규칙만 썼을 때.
  반주먹 이동은 **오작동 회/분**(낮을수록 좋음).
- **학습**: 학습한 데이터를 맞힌 비율. 학습은 높은데 인식이 낮으면 "외우기만 했다" → 다른 자세·다른 날 데이터가 필요.
- **→ 조언**과 상태 칩: 좋아요 / 더 녹화 / 다시 학습.
  - 반복 30회 미만, 자세 3개 미만, 인식 80% 미만, 오작동 0.5회/분 초과 → **더 녹화**
  - 모델보다 새 녹화가 있음 → **다시 학습**
- **[집중 녹화]**: 그 동작만 안내 녹화(자세 3개 × 15회, 반주먹 이동은 자세마다 3분). 손바닥(Dan) 포인터에서 된다.
  녹화 파일 meta에 `focus`가 남는다.

아래쪽:

- 각 동작 왼쪽의 **학습 선택 체크박스**로 이번에 학습할 동작을 고른다. 녹화가 없는 동작은 집중 녹화 후 선택할 수 있다.
- **[녹화된 동작 전체 선택] / [선택 해제]**는 카테고리 필터와 관계없이 전체 목록에 적용된다. 선택한 이름과 개수가 위에 표시된다.
- **[선택 동작 학습 (N)]**: 별도 프로세스로 `train_tcn.py --tasks <동작 키...> --folds --progress`를 돌린다(앱은 계속 쓸 수 있음). 지금 단계(평가 학습 n/3 → 최종), 반복·손실, 경과 초, 손실 곡선이 보인다.
  끝나면 성적이 새로 고쳐지고 **손짓 확인(TCN)이 새 모델을 다시 읽는다**. 녹화 중에는 누를 수 없다.
- 선택한 동작의 이전 녹화와 새 집중 녹화를 함께 사용한다. 중립·휴식과 다른 동작의 수행 구간을 해당 동작이 아닌 예시로 포함한다. 다른 동작의 모델은 수정하지 않는다.
- 좌클릭과 엄지+중지 유지 드래그는 같은 손 모양 클래스를 공유하므로 함께 선택된다. 중립·이동 녹화만 단독으로 학습할 수는 없다.
- 선택한 동작은 별도 모델로 새로 학습한다. 다른 동작의 기존 모델·점수·판정 기준은 그대로 유지한다. 이전 가중치에 이어서 미세 조정하는 방식은 아니다.
- 새 모델 저장·실행 검증이 모두 끝난 뒤 모델 목록을 교체하고 **시험 모드**로 시작한다. 학습 데이터에서 해당 동작 구분률이 50% 미만이거나, 10회 이상 평가한 제외 자세의 분류율이 25% 미만이면 후보만 저장하고 기존 모델을 유지한다. 이 최소 검사는 적용 권장이 아니다. 실패하거나 완료 전에 멈춰도 기존 모델이 유지된다. 모델은 `models/selected/<실행 ID>/`에 누적되고, `gesture_tcn.selected.json`이 동작별 최신 모델을 가리킨다.
- **[내보내기]**: `exports/gesture-tcn-<시각>/`과 같은 이름의 `.zip`. **[폴더 열기]**로 탐색기에서 연다.

**[학습 진행 보기]**에서 별도의 진행 페이지로 이동한다. 선택 학습을 시작하면 이 페이지가 자동으로 열린다.

- 전체 진행률, 경과 시간, 남은 예상 시간과 완료 예상 시각을 표시한다. 처음에는 계산 중이며, 두 차례 이상 관측한 학습 속도로 추정한다. PC 부하와 평가·저장 시간에 따라 달라질 수 있다.
- 현재 단계·반복 횟수, 이번 학습 동작, 녹화·자세·학습 구간 수, 현재 단계의 손실 그래프와 진행 기록을 확인할 수 있다. 자세별 평가 보류도 진행률에 반영한다.
- 학습 반복 뒤 성적 계산·모델 저장 중에는 마무리 중으로 표시하며, 저장·실행 검증을 마쳐야 100%가 된다. 실제 동작에 적용하는 것은 별도 설정이다. 실패와 사용자 중단은 완료와 구분한다.
- **[학습센터로]** 또는 **[닫기]**를 눌러도 학습은 계속된다. 중단하려면 **[학습 멈춤]**을 누른다. 같은 앱 실행 중에는 다시 들어가 마지막 상태와 기록을 볼 수 있다.

창은 Esc나 바깥 클릭으로 닫힌다.

### 방향 변화와 동작별 TCN (2026-11-06)

- 각 동작에서 **기존 규칙 / 시험·기록만 / TCN 적용**을 선택한다. 시험 모드는 점수와 판정 이유만 기록한다. 좌클릭과 중지 유지 드래그는 모델을 공유하지만 적용 여부는 독립적이다. 적용 선택은 해당 모델 버전에만 유효하며, 재학습 후에는 다시 시험 모드가 된다. 전체 TCN 스위치가 꺼져 있거나 검지 포인터 모드이면 TCN은 동작하지 않는다.
- 좌·우클릭은 기존 규칙의 클릭을 즉시 전달한다. 적용된 새 모델은 확률 0.9 이상 2프레임, 안정적인 3D 접촉과 손가락 분리, 재무장할 만큼의 실제 손가락 벌림을 확인하면 규칙이 놓친 클릭을 보완한다. 같은 접촉의 뒤늦은 규칙 클릭은 중복 전달하지 않는다. 손 검출 소실·카메라 시간 단절·다른 동작 중에는 새 클릭을 보완하지 않는다. 드래그·스크롤·모드·방향 모션은 기존 상태 기계와 TCN 확인을 함께 사용한다. 제어 끄기와 모션 모드 빠져나오기는 계속 가능하다.
- `local3d-v1`의 손 기준 좌표는 정확한 3D 관절에 대해 회전·이동·크기에 불변이다. `continuous-v2` 학습 파이프라인은 준비/자세/선택 라벨 때문에 입력 이력을 삭제하지 않는다. 250ms 초과의 실제 프레임 단절만 창을 새로 시작한다. 학습·앱·내보낸 예시가 같은 시간 처리를 사용한다.
- 데이터 증강은 좌우 손의 깊이 반전, 깊이 추정 변화, 작은 관절 오차, 0.75~1.25배 동작 속도를 사용한다. 파생 거리·변위를 다시 계산하고, 패딩과 검출 누락은 0으로 유지하며, 화면 쓸기 방향은 뒤집지 않는다. 클래스·녹화 세션·자세별 균형 샘플을 매 반복 새로 뽑아 긴 중립 녹화의 편중을 줄인다.
- 기본 교차 검증은 자세를 최대 5개 그룹으로 나누어 모든 자세를 한 번씩 학습에서 제외한다. 학습 창에 제외 자세가 걸치는 경계 프레임도 제거한다. `--validation-folds`로 그룹 수, `--samples-per-epoch`(기본 16,384)로 반복당 표본 수, `--threads`로 CPU 병렬도를 지정할 수 있다. 최종 모델은 모든 자세로 학습한다.
- **자세 분류율**과 **녹화 동작 전달**은 별도 수치다. 전달 비교는 기록된 규칙 동작을 실제 TCN 판정 코드로 재생해 규칙/TCN 성공 횟수, 추가·누락 동작, 비동작 구간 오작동, 지시 후 반응 P95를 보여준다. 짧은 클릭 20회·전체 30회·비동작 60초가 없는 클릭 모델은 검증 부족으로 표시한다. 녹화 지시는 실제 의도의 대리 정답이며 다른 날/다른 사람의 성능을 보장하지 않는다.
- 좌·우클릭의 집중 녹화에서 **짧은 클릭 · 각도×속도**를 선택하면 9조건 각각 0.3/0.5/0.7초 클릭을 안내한다. 준비 카운트다운에 맞춰 붙이고 쉬기에서 바로 뗀다. 준비 단계는 손을 편하게 펴도록 안내하며, 동작 지시를 미리 내보내지 않는다. 필요한 조건만 켜고 반복·유지 시간을 수정할 수 있다. 기존 2초 유지 녹화나 중간에 잘린 녹화는 빠른 클릭의 검증을 대신하지 않는다. 학습센터에 짧은 클릭 수집량과 준비 중 규칙 클릭 후보가 많았던 녹화의 안내도 표시한다.
- 실패 기록에 3D 관절, 원래 규칙 동작, TCN 점수와 판정 이유를 함께 저장한다. 카메라 원본 영상은 저장하지 않는다. 손이 완전히 가려져 관절 자체가 보이지 않는 상황은 TCN 학습만으로 해결되지 않는다.

## 3. 내보낸 묶음 (다른 앱에 넣기)

| 파일 | 내용 |
|---|---|
| `gesture_tcn.onnx` | 모델 (입력 `x` = (1, 15, 133), 출력 `logits` = 클래스 3개) |
| `gesture_tcn.json` | 클래스 순서, 창 길이, 판정 기준(확률 0.7 이상 3프레임 연속), 데이터 출처, 동작별 성적 |
| `tcn_features.py` | MediaPipe 관절 → 특징 133개 (모델과 반드시 같은 코드) |
| `gesture_tcn.selected.json`, `selected/` | 선택 학습한 동작의 활성 목록과 모델. 선택 학습을 쓴 경우 포함 |
| `tcn_models.py`, `active-model-report.json` | 기본·선택 모델을 함께 읽는 로더와 현재 동작별 성적 |
| `example_use.py` | numpy + onnxruntime만으로 쓰는 예시 (`GestureModel.step(t, world, image, aspect)`) |
| `README.md` | 위 내용과 성적 요약 |
| `dataset.npz` | 녹화 전체의 프레임별 특징 `x`, 정답 `y`(-1 = 제외), 자세 `posture`, 녹화 번호 `recording` (다른 프레임워크에서 다시 학습할 때) |

입력은 MediaPipe Hand Landmarker의 `hand_world_landmarks`(3D, 미터)와 `hand_landmarks`(화면 정규화), 화면 비율(높이/너비)이다.
선택 학습 결과를 사용할 때는 폴더 전체와 `example_use.py`의 로더를 사용한다. 기본 ONNX 하나만 복사하면 선택 학습 결과가 빠진다. 동작별 독립 확인 점수이므로 합이 1이 아닐 수 있으며, 임계값과 연속 프레임 수는 `class_decisions`를 참조한다.
확인: 내보낸 폴더에서 `example_use.py`로 녹화 6,000프레임을 돌려 프레임 단위로 93% 맞음(2026-11-05).

## 4. 학습 진행 이벤트 (`train_tcn.py --progress`)

한 줄에 JSON 하나. 앱(`src/training_center.py`의 `TrainingJob`)이 읽는다.
`loaded`(구간 수, 자세, folds) → `fold_start` → `epoch`(stage, epoch, loss) → `fold_result` → `final_start` → `epoch`… → `done`(per_gesture).
`models/gesture_tcn.json`에 `per_gesture`, `train_accuracy`, `loss_curve`가 함께 저장된다.

- **녹화는 코드와 같은 브랜치(`feat/tcn-training-app-transition`)에 함께 올린다.** 다른 PC·다른 각도에서 녹화한 파일도 같은 `recordings/`에 쌓고, 학습은 그 폴더 전체로 한다.
- 녹화 파일 이름에 **PC 별명**이 들어간다: `20261105-030947-home-pc-guided.jsonl.gz`. 두 PC가 같은 초에 녹화해도 겹치지 않는다.
  - 별명은 `config/gestures.json`의 `"pc_alias"`(영문·숫자·`-`·`_`). PC마다 다르게 정한다(예: `home-pc`, `office-laptop`).
  - 비워 두면 `pc-` + PC 이름으로 만든 4자리 코드(같은 PC면 늘 같은 코드, 이름은 알아낼 수 없음).
  - **이 저장소는 공개라 실제 PC 이름과 Windows 사용자 이름은 녹화·모델 정보 어디에도 저장하지 않는다**(2026-11-05). 그 전에 만든 녹화 1개는 파일 안에 실제 PC 이름이 남아 있지만, 학습 센터·모델 정보·내보내기에는 코드(`pc-ded5`)로만 나온다.
- 녹화 중에는 `….jsonl.gz.part`로 저장되고, 끝나면 이름이 바뀐다. `.part`는 git에 올라가지 않고 학습에도 쓰이지 않는다.
- **받으면서 학습해도 된다**: 학습은 시작할 때 완성된 녹화 목록을 고정한다. 반쯤 받은 파일이나 끝 줄이 없는 파일(녹화 중 앱이 꺼짐)은 건너뛴다. 진행 줄과 학습 센터에 "다음 학습에 포함 n개"로 표시되고, 다음 학습 때 들어간다.
- **용량**: 학습 센터 위쪽에 "녹화 총 n MB / 분리 권장 500 MB"가 보인다. 500 MB를 넘으면 노란 안내가 뜬다. 그때는 학습 데이터를 전용 비공개 저장소로 옮기는 걸 검토한다. git은 지운 파일도 기록에 남기므로, 옮기기 전에 이미 올린 양은 줄지 않는다. 녹화는 17분에 약 10 MB다.
