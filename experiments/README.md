# 독립 실험 앱

[Touch Desktop](touch-desktop/README.md)은 검지 이동·누르기 클릭, 편 손 스크롤·잡기,
엄지·검지 확대를 별도 Electron 화면에서 시험하는 재구성 앱입니다.
실행 방법, 저장 시점의 검증 결과와 남은 작업은 해당 README에 정리했습니다.

[Fist Mouse Lab](fist-mouse-lab/README.md)은 주먹 이동, 엄지 클릭·드래그,
새끼손가락 우클릭, 검지 휠을 시험하는 Windows 앱입니다.

`fist-mouse-lab/setup.bat`으로 환경을 준비한 뒤 `fist-mouse-lab/run.bat`으로 실행합니다.
설정과 점검 기록은 각 PC에만 저장합니다. 테스트도 해당 앱 폴더에서 실행합니다.

이 브랜치는 `hand-mouse-gesture-overhaul`의 `dc82b79`를 기준으로 합니다.
기준 커밋에 있던 팀원 앱 파일은 수정하지 않았습니다. 현재 실험을 그 앱에 통합한 버전은 아닙니다.
