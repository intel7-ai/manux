# 코드와 검증 범위

2026-11-04까지 개발한 독립 Fist Mouse Lab의 소스 스냅샷입니다.

- 카메라 최신 프레임 처리, 손 연결, 회전 재검출, 필터는 로컬 Tracking Lab에서 가져왔습니다.
- 주먹 마우스 판정, 절대 좌표 매핑, 엄지 클릭/드래그 구분, 120Hz 목표 출력과 점검 화면은 이 앱에 포함합니다.
- 모델은 저장소에서 사용하던 `hand_landmarker.task`입니다. 개인 등록은 임계값 보정이며 모델 파인튜닝이 아닙니다.
- 개인 임계값, 원시 관절 기록, 카메라 영상, 로컬 절대 경로를 담은 작업 이력은 게시하지 않습니다.

로컬에서 자동 테스트 95개와 전용 Windows 창의 클릭·더블클릭·우클릭·드래그·휠 출력 검사를 통과했습니다.
공유본에는 개인 재생 기록이 없으므로 그 기록을 읽는 테스트 하나는 건너뜁니다.
사용자가 보고한 클릭/드래그 혼동과 가장자리 인식 문제는 수정 후보를 적용한 상태이며,
최신 버전의 실제 손 사용감과 정확도는 추가 점검이 필요합니다.
