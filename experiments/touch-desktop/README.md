# MANUX Touch Desktop

검지로 이동하고 누르는 동작으로 클릭하는 Windows용 독립 실험 앱입니다.
기존 Dan/Park 앱과 Fist Mouse Lab은 수정하지 않고, 별도 폴더에서 실행합니다.

## 실행

Windows, Python 3.12, Node.js/npm, 웹캠이 필요합니다. 이 폴더에서 최초 한 번 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm install
```

이후 `run.bat`을 실행합니다. 기본 모드는 앱 안에서만 작동하는 **연습**입니다.
`PC 제어 시작`을 누르면 실제 Windows 마우스 입력을 보냅니다.
Esc, Ctrl+Alt+M 또는 실제 마우스 이동으로 PC 제어를 멈춥니다.

다른 Python 환경을 쓰려면 `MANUX_PYTHON`에 해당 `python.exe` 경로를 지정합니다.
개발 PC에서는 인접한 `manux-dan-personal`의 Python과 `manux-park-20261104`의 Electron을 사용할 수 있습니다.
다른 팀원의 PC에서는 위 설치 과정으로 이 폴더 안에 독립 환경을 준비하세요.

## 현재 동작

| 기능 | 손동작 |
|---|---|
| 이동 | 검지를 가리킨 자세에서 손 이동 |
| 클릭 | 검지를 누르듯 움직였다가 원래 자세로 복귀 |
| 더블클릭 | 클릭 동작 두 번 |
| 스크롤 | 손바닥을 완전히 펴고 위아래로 시작. 손을 접으면 종료 |
| 잡고 놓기 | 물체를 가리킨 뒤 손바닥을 펴고 좌우로 시작. 이후 자유롭게 이동하고 손을 접어 놓기 |
| 확대·축소 | 엄지·검지를 잠시 모아 시작한 뒤 간격 조절 |
| 확대 확정 | 손바닥을 펴서 배율 확정. 손을 편하게 접으면 다시 이동 |

상단 탭에서 한 동작만 시험할 수 있습니다. 선택한 동작 범위는 연습과 PC 제어에 동일하게 적용합니다.
손 이동 범위·떨림 보정·누르기 깊이와 10초짜리 개인 검지 등록을 제공합니다.
1080p/720p, 좌우 반전, 90도 단위 회전을 지원합니다.

## 이번에 다시 만든 부분

- 검지 끝과 손바닥의 상대 변화를 먼저 검사합니다. 손가락이 접히거나 추정점이 급변한 프레임을 곧바로 커서 이동으로 보내지 않습니다.
- 클릭과 손 재진입 후에는 현재 보이는 커서 위치에 손 좌표를 다시 연결합니다. 시간에 따라 이전 절대 좌표로 끌려가는 보정은 제거했습니다.
- 클릭은 누름과 복귀가 완료되어야 발생합니다. 잡기는 별도 상태에서 버튼을 누르고, 손 접힘·추적 중단·종료 시 해제합니다.
- 확대 확정 후에는 배율을 고정하고, 편 손이 곧바로 잡기나 스크롤로 해석되지 않게 했습니다.
- 카메라 캡처, 추적·판정, 커서 출력, Electron 화면을 분리했습니다. 대기 중인 영상은 가장 최근 프레임만 사용합니다.
- 연습 화면은 선택·더블클릭·스크롤·카드 이동을 실제 화면 이벤트로 처리합니다. 동작 판정과 대상이 받은 입력을 구분합니다.

## 구조

```text
카메라 → LatestCamera → MediaPipe / TrackingCore
                           ↓
                     Observation
                           ↓
                      Controller
                  ↙                 ↘
          연습 화면 이벤트        Windows 입력
          Electron / IPC        CursorMotion / SendInput
```

- `engine/observation.py`: 관절을 손바닥 기준 특징으로 변환
- `engine/controller.py`: 동작 상태 전환과 실행 의도 생성
- `engine/pointer.py`: 손 재연결, 화면 전체 매핑, 떨림 보정
- `engine/output.py`: 연습/Windows 출력 전환
- `engine/worker.py`: 카메라·추적·IPC·로컬 기록
- `ui/`: 실제 이벤트를 받는 연습 화면과 설정
- `main.cjs`, `preload.cjs`: Electron 창 및 제한된 IPC

추적·복구·필터·Windows 출력의 일부는 기존 실험 코드에서 가져왔습니다.
새 모델 학습이나 MediaPipe 파인튜닝을 한 것은 아닙니다.

## 검증 상태 — 2026-11-04 저장 시점

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests
node --test tests/workspace.test.cjs
```

Python 회귀 검사 23개, 화면 동작 모델 검사 3개가 통과했습니다.
15/20/30/60 FPS의 클릭·더블클릭, 기록에서 확인한 검지 좌표 급변, 손 재진입,
스크롤 방향 고정·정지, 잡기 해제, 확대 확정을 검사합니다.
좌표 급변 검사는 실제 기록에서 확인한 좌표 쌍을 통제된 자세에 넣은 회귀 검사입니다.
실제 사용자 의도에 대한 인식 정확도를 측정한 결과는 아닙니다.

새 창에서 카메라 1920×1080 연결 및 약 30 FPS의 추적 동작을 확인했습니다.
마지막 화면 커서 피드백 수정은 저장했으며, 실행 중인 앱에는 재시작 후 반영됩니다.
Windows 자체 입력 검사는 검사 창의 포커스가 없어 중단했고, 이후 Esc로 컴퓨터 조작이 중단되었습니다.
**현재 저장본에서 실제 Windows 클릭·드래그 전체 검증은 아직 완료하지 못했습니다.**

검사를 이어가려면 아래 스크립트의 자체 검사 창에서 `입력 검사 시작`을 누릅니다.
검사 창이 포커스를 잃으면 즉시 중단합니다.

```powershell
.\.venv\Scripts\python.exe scripts/verify_native.py
```

## 남은 작업

- 실제 손으로 작은 대상 클릭·더블클릭·놓기 성공률과 반응 시간을 측정하고 조정
- 마지막 화면 피드백 변경을 재실행 후 확인하고 Windows 자체 입력 검사 완료
- 확대 전환 시 검지 누름과 엄지·검지 모으기의 혼동 확인
- 개인 검지 등록의 표본 분산·분리도 검증 강화
- 이전 실험의 우클릭·손날 페이지 넘김은 이 새 컨트롤러에 아직 옮기지 않음
- 카메라가 옆이나 위에 설치된 경우를 위한 자유 각도 영점 조정은 미구현. 현재는 반전·90도 회전만 제공

## 개인 데이터

설정은 `.local/`, 상태·최근 관절 수치 기록은 `.runtime/`에만 저장합니다.
두 폴더는 Git에서 제외합니다. 카메라 영상은 화면 미리보기에만 사용하고 파일로 저장하지 않습니다.
기록에는 관절 좌표와 판정 결과가 들어갑니다. 의미 있는 손 기록이 대기 화면으로 덮이지 않도록
`last-hand-session.json`을 별도로 유지합니다. 개인 기록은 이 저장본에 포함하지 않았습니다.

`scripts/replay.py`는 로컬 기록이 있을 때만 쓰는 분석 도구입니다.
손이 충분히 포함되지 않은 기록으로는 개선 여부를 판정하지 않습니다.
