### 1.2 하이브리드 결합 상수 검증 세트 기반 탐색 (`blend_tcn_and_spatial_probs`)
15-fold 조건 분리(Leave-Condition-Out) 검증 예측값 위에서 중립 이동(`none`) 오발화율을 상한(`<= 1.20/min`) 이하로 묶어 두고 재현율(Recall)을 최대화하는 결합 상수를 그리드 탐색하여 적용하였다:
- `spatial_alpha = 0.40` (기존 `0.42`)
- `spatial_veto_threshold = 0.80`, `spatial_veto_target_cap = 0.15`
- `spatial_boost_threshold = 0.85` (단, `hold_seconds > 0`인 고위험 동작은 0-lag 부스트 자동 비활성화)

### 1.3 Post-hoc Temperature Scaling 확률 보정 (`src/spatial_mlp.py`, `src/gesture_gate.py`)
모델의 argmax 분류 결과는 전혀 변경하지 않으면서 출력 확률이 실제 정답 적중률과 일치하도록 Post-hoc Temperature Scaling($p_i(T) = \text{softmax}(\log p_i / T)$)을 구현하고 Leave-Out 검증 세트에서 NLL/ECE를 최소화하는 최적 온도 $T$를 피팅하였다.

### 1.4 사용자 취소·`F` 키 기반 검증 가능 부정 후보 로깅 (`src/failure_log.py`, `src/qt_runtime.py`)
- 사용자가 오작동 직후 1.0초 이내에 일시정지(`Space`/`Esc`/Pause 버튼)로 동작을 취소(`source="user_cancelled"`)하거나, 실시간 사용 중 `F` 키 / 실패 기록 버튼(`source="f_key"`)을 누르면 직전 2.5초 랜드마크 시퀀스(최대 25프레임)와 의심 동작·제스처·보정 확신도·기각 사유를 `logs/failures/negative_candidates.jsonl`에 기록한다.
- **안전장치 (`auto_retrain=False`, `verified=False`)**: 미검증 사용자 취소 로그가 자동 재학습 파이프라인에 무분별하게 유입되어 결정 경계를 오염시키는 것을 원천 차단하였다.

### 1.5 UI 보정 확신도 및 거절/보류 사유 실시간 노출 (`src/qt_dashboard.py`, `src/dashboard.qml`)
- `GestureGate.status_summary()` 및 `rejection_reason_ko()`를 통해 대시보드 TCN 게이트 하단에 실시간 **보정 확신도(`%`, 온도 `T` 병기)**와 **거절/보류 사유**(입력 품질 낮음, 미등록 손모양/OOD 의심, 중립·이동 손모양 억제, 고위험 동작 유지 시간 미달, 확신도/연속 프레임 미달) 및 누적 보류 카운터를 실시간 표시한다.

## 4. 잔여 위험(Remaining Risks) 및 Stage 8 이관 과제

1. **개인별 손 크기·핀치 습관 및 미등록 커스텀 동작 확장 필요**:
   - Stage 7의 위험도별 정책으로 `thumb_ring` Leave-Out 재현율이 `52.8% → 62.9%`로 크게 상승하고 오발화가 `1.13/min`(Deployed `0.96/min`)까지 감소했으나, 여전히 사용자별 고유한 손가락 길이 비율이나 중지(`thumb_middle`) 핀치 깊이에 따른 조건 간 편차가 존재한다.
2. **Stage 8 해결 방향**:
   - 1~2분 온보딩(손 펴기 → 핀치 → 이동 → 30초 평소 이동)을 통해 사용자 맞춤 프로토타입 블렌딩, 개인화된 핀치 비율/OOD 임계값 보정, 조명·손 크기 경고를 프로필에 저장한다.
   - 고정된 인코더(`encoder_frozen=True`) 위에서 3~5회 반복만으로 새 커스텀 제스처 프로토타입을 등록(근접도 경고 및 30초 중립 이동 오발화 사전 검증 포함)하고, 섀도우 모드 및 롤백 가능한 제한적 EMA 적응을 마지막으로 결합한다.
