# 학습 일시중지·이어하기 (2026-11-09) — AI agent용 메모

한 줄 요약: **학습은 "자세 하나를 빼고 평가"하는 판(fold)마다 결과를 `logs/fold_cache/`에 저장하고, 다시 시작하면 끝난 판은 건너뛴다.** 일시중지는 신호 파일, 이어하기는 `last_job.json` 표시로 구현했다. 최종 모델 학습(마지막 한 판)은 저장 대상이 아니다.

## 1. 무엇이 어떻게 동작하나
| 기능 | 방법 | 파일 |
|---|---|---|
| 판 결과 저장 | 판이 끝날 때마다 `logs/fold_cache/<키>/fold_<자세>.pkl`. 임시 파일에 쓰고 `fsync` 뒤 `os.replace`(반쯤 쓴 파일이 남지 않음) | `src/fold_cache.py` `FoldCache.save` |
| 이어하기(건너뛰기) | `train_tcn.py --resume`이 같은 키의 저장된 판을 읽어 결과와 이벤트를 되살리고 건너뜀 | `scripts/train_tcn.py` 판 반복문 |
| 일시중지 | 앱이 `logs/fold_cache/PAUSE` 파일을 쓰면, 학습이 **다음 판을 시작하기 전**에 확인해 종료 코드 **75**로 끝남(`paused` 이벤트). 지금 판은 끝까지 한다 | `src/fold_cache.py` `request_pause` |
| "끝나지 않은 학습" 표시 | `logs/fold_cache/last_job.json`(시작 옵션과 판 수). 학습을 시작할 때 쓰고, **정상 종료**하거나 **버리기**를 누르면 지움. 정지·일시중지·강제 종료 때는 남음 | `src/training_center.py` `TrainingJob` |
| 화면 | 학습 중 배너: **일시중지**(요청 뒤엔 숨김) / **학습 멈춤**. 학습 센터 배너: `끝나지 않은 학습 · 평가 N/M판 저장됨` + **이어서 학습** / **버리기** | `src/dashboard.qml`, `src/qt_dashboard.py` |

**선택 동작 학습(`--gestures`, 앱의 동작 행 "학습")은 다른 스크립트(`scripts/train_selected.py`)로 돈다.** 전체 학습에만 넣었다가 선택 동작 학습에는 없다는 것을 뒤늦게 알았고(사용자가 "학습 멈춤"을 누르려던 학습이 선택 동작 학습이었다), 같은 방식으로 추가했다: 동작(label)마다 별도 키(`"kind": "selected"`, `"label"`)로 판 결과(`results`)를 저장하고, 판 시작 전과 최종 모델 학습 전에 `PAUSE`를 확인한다. 여러 동작을 한 번에 학습할 때 `prune_except`가 그 동작들의 키를 모두 남긴다. 한 동작의 최종 모델은 학습이 끝날 때까지 게시되지 않으므로, 일시중지가 동작 사이에 걸리면 앞 동작의 최종 모델은 이어서 할 때 다시 학습한다(평가 판은 건너뜀). **이 변경은 이미 돌고 있던 학습에는 적용되지 않는다.**

앱의 "학습 시작"과 `studio.bat` 4번은 자동으로 `--resume`을 붙인다. CLI에서 직접 실행할 때는 `--resume`을 붙여야 켜진다.

## 2. 재사용 조건 (핵심)
저장된 판은 아래가 **모두 같을 때만** 쓴다. 하나라도 다르면 키가 달라져 처음부터 학습하고, 다른 키의 저장 결과는 시작할 때 지운다(`prune_others`).
- 녹화 파일(이름, 크기, 수정 시각)
- 옵션: 시드, 임계값, 연속 프레임 수, 에폭 수, 윈도 간격, 장치, `--keep-rest`, `--hard-negatives`와 그 값, `--threshold-sweep`, 오프라인 증강, `--no-cleaned`, `TCN_LARGE_BATCH`
- 클래스, 평가 자세 목록
- 코드: `train_tcn.py`, `spatial_mlp.py`, `tcn_features.py`, `capture_dataset.py`, `gesture_catalog.py`, `evaluation.py`의 내용 해시(`CODE_FILES`)

그래서 **위 코드 파일을 고치면 이어하기가 막힌다**(의도된 동작). 키 구성 코드는 `train_tcn.py`의 `FoldCache(...)` 호출 부분에 있다.

## 3. 갑자기 꺼졌을 때
- 앱·PC가 강제 종료돼도 `last_job.json`과 끝난 판 파일은 디스크에 남는다. 다음에 앱을 켜면 이어하기 배너가 뜬다.
- 저장 도중 꺼지면 임시 파일(`.tmp`)만 남고 `load`가 읽지 못하는 파일은 무시한다 → 그 판만 다시 한다.
- 잃는 것: 진행 중이던 판 하나(GPU 약 40초, CPU 약 80초) + 최종 모델 학습 구간.

## 4. 시험과 확인한 것
- 단위 시험: `tests/test_fold_cache.py`(키 일치·불일치, 끄기, 깨진 파일, 정리, 일시중지 신호, 끝나지 않은 학습 찾기·재시작 옵션·버리기, 실행 중에는 제안 안 함). 전체 582개 통과.
- `tests/conftest.py`가 `src.fold_cache.CACHE_ROOT`을 임시 폴더로 돌린다. 그러지 않으면 `TrainingJob.start`를 쓰는 기존 시험이 진짜 `logs/fold_cache/last_job.json`을 만들어 앱에 가짜 이어하기 배너가 뜬다(실제로 한 번 생겼고 지웠다).
- 실제 학습에서 판 하나(`fold_0.pkl`)가 저장되는 것은 확인했다.
- **선택 동작 학습(`train_selected.py`)의 판 저장·일시중지는 문법 검사와 전체 시험(582개 통과)만 했고, 실제로 학습을 끊었다가 이어 돌려 보지는 않았다.**
- **확인하지 못한 것:** (a) 학습을 끊었다가 `--resume`으로 이어 돌려 결과가 같은지 확인하는 시험을 끝내지 못했다. 첫 시도는 새 녹화를 읽다가 시간 제한에 끊겨 저장된 판이 없었고, 두 번째는 다른 학습과 GPU를 나눠 쓰다가 끝났다(아래 6절). (b) 화면의 일시중지·이어서 학습 버튼은 앱을 띄워 눈으로 확인하지 못했다. (c) 일시중지 종료 코드 75를 앱이 받아 "일시중지됨"으로 표시하는 경로는 단위 시험이 없다.

## 5. 조사할 때 먼저 볼 것
1. 이어하기가 안 되고 처음부터 시작하면: 위 2절의 항목 중 바뀐 것이 있는지. 녹화 파일이 하나라도 새로 생기거나 코드가 바뀌면 정상적으로 처음부터다.
2. 가짜 이어하기 배너가 뜨면: `logs/fold_cache/last_job.json`이 남은 것. 시험이나 비정상 종료 뒤 남을 수 있다. 앱의 **버리기**를 누르거나 파일을 지운다.
3. 일시중지를 눌렀는데 안 멈추면: 학습은 판 경계에서만 확인한다(판 하나 약 40~180초). `logs/fold_cache/PAUSE` 파일이 남아 있는지, 학습 프로세스가 `--resume` 없이 옛 버전으로 시작된 것은 아닌지(옛 버전은 신호를 보지 않는다).
4. 옛 버전으로 시작한 학습에는 이어하기도 일시중지도 없다. 앱을 새로 켠 뒤 시작한 학습부터 적용된다.

## 6. 같은 GPU로 두 학습을 동시에 돌리지 말 것
2026-11-09 13:00 무렵 앱의 `thorough` 학습과 이어하기 시험을 같은 GPU(RTX 3050, VRAM 6 GB 중 5.9 GB 사용)에서 동시에 돌려 둘 다 크게 느려졌다(앱 판당 약 3분). 사용자가 앱 학습을 끈 시각에 시험 쪽이 `CUDA error: an illegal memory access`로 죽었고 `nvlddmkm` 이벤트 153이 3건 기록됐다. 원인은 확정하지 못했다(동시 사용, 다른 프로세스를 끄는 순간의 영향, 같은 날 반복된 PCIe 오류 `WHEA-Logger 17` 중 무엇인지 모름). 학습은 한 번에 하나만 돌릴 것(`docs/gpu-training.md` 8절).
