# 그리기 모드 (2026-11-10)

모니터에 손으로 모양을 그리면 그 모양에 연결한 명령이 실행된다. 코드: `src/draw_mode.py`, `src/stroke_recognizer.py`, `src/DrawOverlay.qml`, 설정은 `src/dashboard.qml` `palmSettings`.

## 쓰는 법
- [설정] → 그리기 모드 → 켜기. 켜져 있는 동안 다른 손 조작(클릭·스크롤 등)은 쉰다(모션 모드와 같은 방식). OS 커서는 움직이지 않는다.
- 펜: **검지만 펴서 가리키면 내려가고(펜 = 검지 끝), 손을 펴거나 쥐면 올라간다.** 가리킴 = 검지 펴짐, 중지·약지·새끼 접힘(엄지 무관), 3D로 판정(화면 쪽을 가리켜 검지가 카메라를 향해도 짧아 보이지 않게). 카메라 화면의 가상 손 박스 = 모니터 전체.
- 2026-11-10 사용자 보고("손가락 모아가지고는 선이 끊어져서 인식을 못한다 대부분")로 엄지+검지 집기에서 바꿨다. 0.3초(`PEN_GRACE`)보다 짧은 끊김(손가락이 잠깐 굽어 보임, 손을 잠깐 놓침)은 선을 끊지 않는다.
- 녹화에서 가리킴으로 잘못 보는 비율(프레임): 쉬는 중 1.1%, 엄지+중지 5.6%, 그 밖의 동작 0~0.2%(펜이 내려가려면 2프레임 연속 + 일정 길이 이상). 실제로 가리켜 그린 녹화가 없어 인식률은 아직 모름.
- 펜이 올라갈 때마다 그 획을 알아보고 명령을 실행한다. 여러 모양을 이어서 그릴 수 있다.
- 끄기: 설정의 버튼, 또는 엑스(✕, 한 획) 그리기(기본 명령 `toggle_draw`).

## 모양과 명령
- 기본 모양 6개와 기본 명령(바꿀 수 있음): 원=F5, 체크=Enter, 삼각형=미디어 재생/정지, Z=Ctrl+Z, 사각형=Win+Shift+S, 엑스=그리기 모드 끄기. 기본값은 메모리에만 두고 파일에 쓰지 않는다(사용자가 바꾸면 `config/gesture_bindings.json`에 저장).
- 새 모양: 설정의 그리기 칸에 마우스로 1~3번 그려 등록 → [명령]으로 연결(단축키·키 기억하기·유튜브·마우스·프로그램). 예시를 더하면 더 잘 알아본다. 모양은 `config/draw_shapes.json`(이름과 예시 좌표만).
- [시험해 보기]: 마우스로 그려 어떤 모양으로 알아보는지 확인.

## 인식기
$1 방식 템플릿 비교에 다음을 바꿨다: 균등 크기 맞춤(납작한 모양 유지), 작은 회전(±20°)만 허용, 양방향, 닫힌 모양은 시작점 무관(16곳), 위치 + 진행 방향(3점 현) 함께 비교(`DIRECTION_SCALE` 6). 기준 점수 80%(설정에서 60~95%), 2등과 3% 이상 차이.

## 잰 값 (합성 획만, 실제 손 획은 아직)
기본 모양을 흔들림(부드러운 0.05 + 잡음 0.008)·±15° 기울기·가로세로 0.8~1.2배·반대 방향으로 만든 획 360개: 339개(94%) 인식, 사각형→원 혼동 7개. 무작위 낙서 200개 중 통과 0개. `DIRECTION_SCALE` 1→6에서 사각형→원 혼동 44→7. 실제 손으로 그린 획은 측정 전이다.
