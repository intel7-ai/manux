- `manux-logo.png`: 프로젝트 기존 MANUX v9 가로 로고의 어두운 배경용 PNG. 원본 artwork를 변경하지 않고 발표에 배치했다.
- `player-evidence.png`: 2026-10-29 자동 브라우저 점검의 `test-results/desktop.png` 중 영상 플레이어·카메라 제어 영역을 잘라 사용했다. 원본 카메라 시험은 합성 입력을 사용했으며 실물 인식 성능의 증거가 아니다.

손 사진 원본 출처는 저장소의 [fixtures 출처](../../../tests/fixtures/sources.json)에 있다. PPT 7~8장과 발표 대본에도 시험 화면의 성격을 표시한다. 이 폴더에는 원시 사용자 카메라 영상이나 개인 프로필을 포함하지 않는다.
