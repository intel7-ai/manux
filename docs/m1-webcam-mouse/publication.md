## 현재 Jira 계획과의 차이

## 게시 검증과 한계

검증 범위는 게시 파일 목록, 상대 문서 링크, 로컬 절대경로 제거, 문서 구문, 제품 코드와의 분리, 연구/시험/구현 주장의 구분이다. 실제 명령·결과는 PR 설명에 기록한다. 문서 전용 변경이므로 새 동작을 구현하거나 웹캠·OS 입력을 실행하지 않았다. 저장소의 CI 결과 역시 별도로 확인하며 제품의 실사용 증거로 표현하지 않는다.
