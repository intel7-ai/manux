# AI 동작 추가 원본 이식

기준: 현재 앱 `f1a88ee`, 가져올 기능 `origin/feat/hand-mouse-20261112@a700452`.
현재 UI·클릭·커서·휴대폰·MLP 모델 설정은 유지한다.

원본 `dashboard.qml`의 `llmDialog`와 그 안에서 사용하는 공통 컴포넌트 및 색상은 그대로 추출한다.
원본 `qt_dashboard.py`의 AI·손 모양 등록·학습·연결 목록 메서드를 이식한다.
제안 스키마, 프롬프트, 검증, 히스토리, 복합 동작, 연속 동작, 그리기·회전, 개인 손 모양 학습은
`compat/hand_mouse`에서 원본 구현을 사용한다. 출처 해시는 `upstream.json`에 기록한다.

호스트 차이로 필요한 변경:

- import 경로와 저장 경로: 사용자 프로필의 `ai-customization/` 아래에 별도 저장한다.
- 원본 학습의 '아님' 검증 자료는 같은 녹화 형식인 현재 앱의 사용자 녹화 폴더에서 읽는다. 녹화를 복사하거나 기존 모델을 바꾸지 않는다.
- Windows 실행 및 매크로는 `output/windows`, 키 조회와 암호화는 `platform`, 메모리 영상 자르기는 `tracking`에 둔다.
- 기존 카메라 관절·엔진 상태를 어댑터로 전달한다. 현재 기본 매핑은 유지하며 사용자가 적용한 연결만 추가한다.
- 새 화면이 열려 있거나 동작을 등록할 때 현재 엔진의 busy 상태로 실제 제스처 명령을 막는다.

원본 브랜치의 개인 설정·예제·학습 모델·녹화·API 키는 복사하지 않는다.

원본 다이얼로그는 1280×860 화면을 기준으로 구성되어 있다. 현재 메인 창을 변경하지 않고
이 새 기능의 팝업에만 원본 작업 공간을 확보한다. 다이얼로그 본문·컴포넌트·문구는 원문 그대로다.

OpenAI 연결은 최신 API의 `max_completion_tokens`를 사용하며, GPT-6 Luna는 이 짧은 동작 연결 요청에
`reasoning_effort=none`을 사용한다. 다른 제공자의 요청 형식은 유지한다.
사용자가 승인한 환경 파일은 `llmEnvFile/<provider>` 경로로 연결할 수 있다. 앱 설정에는 경로만
저장하며 키를 복제하지 않는다. 연결 해제는 경로만 지우고 원본 환경 파일은 보존한다.
