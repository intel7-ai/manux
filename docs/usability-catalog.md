# v0.5 기본 동작 목록·모션 모드 사용성 실험

2026-11-07 인계 §4.8. **실험 설계이며 아직 결과가 없다.** 한 사람 30분의 사용성 관찰이다.
제품 인식률이나 사람·거리 일반화 평가가 아니다. 규칙/MLP/TCN 비교는 별도 세션 분리 평가를 따른다.
동작 삭제·기본 꺼짐의 최종 결정은 결과와 함께 Sean에게 묻는다.

## 관찰할 동작

빈도는 아래 과제에서의 **예상 사용 기회**다. 실제 사용 횟수를 측정 전 수치로 채우지 않는다.
녹화 카탈로그의 과제와 실행 가능한 기능을 구분한다. `none`은 명령이 아니다.
모션 모드 진입/종료 자체가 사용자에게 필요한지, 같은 일을 클릭·스크롤로 끝내는 편이 쉬운지도 기록한다.

`rock_sign`·`swipe_down`은 실행 가능 명령의 성공률 분모에 넣지 않는다.

## 혼자 하는 30분 과제

조건은 한 번 정하고 유지한다. PC·카메라는 별명으로, 앱 버전/커밋·입력 방식·판정 정책·감도·조명·거리만 적는다.
실명, 원시 영상, 계정 정보, 열었던 개인 문서는 기록하지 않는다. 스크롤과 브라우징에는 공개 페이지·민감하지 않은 PDF를 쓴다.
시작 전 저장할 작업을 저장하고, 원치 않는 출력이 멈추지 않으면 메인 제어 버튼으로 끈다.
장애가 생긴 시간도 제한 시간에 포함하고 억지로 과제를 완료하지 않는다.

| 시간 | 과제와 순서 | 기록 |
| --- | --- | --- |
| 0–2분 | 메인에서 관절/조작 손을 확인. V로 끄기·켜기를 각각 한 번. 기본 이동과 주먹 정밀로 같은 큰 목표를 가리킨다. | V 시도·재시도, 켜짐/꺼짐 이해 여부, 속도 첫인상 |
| 2–5분 | 제어 켠 채 명령을 의도하지 않고 편한 손 자세·손 내리기·팔 위치 바꾸기를 한다. 카메라는 유지한다. | **중립 노출 3분**, 원치 않는 클릭·바탕화면·모드 전환·토글 각각 세기 |
| 5–13분 | 쉬운 지뢰찾기 한 판. 칸 열기·깃발 세우기를 번갈아 시도. 작은 칸은 주먹 정밀 사용. 마지막 1분은 검지 포인터 방식으로 같은 크기 칸 5개 비교. | 목표 클릭 성공/시도, 잘못 연 칸·우클릭, 큰 이동/정밀 전환 불편 |
| 13–20분 | 공개 웹페이지의 링크 3개 열기, 세로 스크롤 왕복, 탭 2개 전환. 엄지 위로 모션 진입 후 뒤로/앞으로·이전/다음 탭을 한 번씩 수행하고 종료. | 이동·스크롤·각 모션 성공/시도, 진입/종료 소요·재시도, 원치 않는 명령 |
| 20–26분 | PDF 3페이지 내려갔다 한 페이지 돌아오기. 스크롤로 먼저 수행하고, 앱의 페이지 버튼도 클릭. 바탕화면 보기 1회 후 PDF 복귀. 1분 남으면 원하는 클릭 방식 비교. | 페이지 지나침·관성 보정, 바탕화면 의도/오작동, 대안과 불편 차이 |
| 26–30분 | 아래 표를 채우고 모션 모드가 없었다면 어떤 과제가 어려웠을지 한 문장. 제일 불편한 3개와 유지하고 싶은 3개를 고른다. | 불편 1–5, 사용 빈도, 변경 제안과 근거 |

카메라 끊김·앱 정지 때문에 사용 못 한 시간은 따로 적는다. 실제 활성 시간과 중립 시간을 분모로 쓴다.
의도한 동작은 한 번 자세를 만들고 중립으로 돌아오기까지 **한 시도**다. 같은 자세의 연속 프레임을 새 시도로 세지 않는다.
요청한 동작이 안 되어 재시도하면 실패 1회와 다음 시도 1회를 기록한다. 잘못된 명령이 나오면 실패와 오작동을 모두 센다.

오작동은 의도하지 않은 **명령 이벤트**다. 멈추지 않는 스크롤·눌린 버튼은 한 사건으로 기록하고 지속 시간·복구 방법을 덧붙인다.

## 결과를 보기 전에 정하는 제안 기준

다음 기준은 **Sean에게 올릴 후보 판정**이며 자동 적용·자동 삭제 규칙이 아니다.

| 관찰 | 제안 | 추가 확인 |
| --- | --- | --- |
| 동작별 중립 오작동이 분당 1회 이상 | 기본 꺼짐 후보 | 실제 중립 노출·사건 로그와 함께 Sean 승인 요청 |
| 원치 않는 버튼 유지·앱 이탈 때문에 작업 포기 | 해당 경로 수정 우선, 다음 사용 전 재확인 | 단발 한 사건이어도 영향·복구를 남김 |
| 의도한 시도가 5회 이상이고 성공이 80% 미만 | 임계값·동작 또는 대안 개선 후보 | 한 사람 소수 시도 결과로 인식률 일반화 금지 |
| 불편 4–5점 또는 대안보다 2점 이상 나쁨 | 모션 진입 생략·대체 동작 후보 | 진입·명령·종료 중 무엇이 불편한지 구분 |
| 30분 동안 자발 사용 0회 | 기본 목록 제외 **후보** | 각본상 기회가 없었던 기능은 미평가로 남김 |
| 성공 80% 이상·불편 1–2·중립 오작동 없음 | 유지 후보 | 표본이 적어도 ‘안전/정확도 보장’으로 표현하지 않음 |

기준이 충돌하면 피해가 큰 오작동 수정부터 제안한다. 단지 드물다는 이유로 필수 접근 경로를 없애지 않는다.
각본에서 지시한 사용과 스스로 필요해 쓴 사용을 분리한다. 창 닫기 후보 표본은 실행 기능 유지/삭제 판정 대상이 아니다.
