# hand-mouse 5차 (2026-11-04 오후): 실사용 오작동 정리, 손 모양 명령 추가

앞선 4차(`jira-20261104.md`) 이후 같은 날 오후에 실사용하며 나온 문제를 `logs/failures`로 원인을 확인해 고쳤다. 수치는 모두 **로그를 같은 코드로 다시 돌린 결과**이며 정확도가 아니다(정답 라벨 없음, 한 사람의 데이터, 기록 창이 겹쳐 부풀려진 값 포함).

## 1. 반주먹 커서 이동 중 오작동 정리
- 모션 모드 토글: 반주먹(손가락 굽힘 1.05~1.4)이 진입 자세로 읽혔다. 굽힘 기준 1.2 → 1.05, 정지 허용 0.05 → 0.03.
- 바탕화면 보기(Win+D): 반주먹에서 손을 펴면 발동. 굽힘 직후 대기 1초 → 2초, 손가락 펴짐 기준 1.45 → 1.55. 발동 시 `desktop` 기록을 남기게 했다.
- 좌클릭/우클릭: 엄지가 깊이 접은 중지·약지에 닿아 클릭으로 읽혔다. 반주먹이면 접촉 0.03 이하, 주먹 직전과 "다른 손가락도 접힌 채 중지만 깊이 접힌" 모양은 클릭 시작 금지. 클릭 발동 시 `click` 기록을 남기게 했다.
- 스크롤: 반주먹을 풀면서 엄지가 검지를 스칠 때 시작됐다. 반주먹 직후 0.5초는 접촉이 0.3초 유지돼야 한다.
- 로그 재생: 좌클릭 125 → 106, 우클릭 29 → 20(전체 기록, 겹침 포함). 의도한 클릭이 줄었는지는 로그로 알 수 없다.

## 2. 모션 모드 진입 자세
- 엄지 "펴짐"을 위치(손가락뿌리와의 거리)에서 **곧은 정도**(뿌리-끝 거리 / 세 마디 합, 0.95~1.0 vs 구부린 엄지 0.36~0.72)로 바꾸고, 엄지가 **위를 향할 때만**(cos 0.7) 진입. 카메라를 향한 주먹(손바닥 폭/길이 2.0 이상)은 제외.
- 기록의 손가락이 접힌 프레임 중 옛 기준으로만 통과한 것 378프레임(구부러진 엄지), 새 기준으로만 통과한 것 25프레임.

## 3. 바탕화면 보기
- 엄지를 접고 네 손가락이 **가로로 누운**(수평에서 약 45도 이내) 손일 때만. 유지 시간 0.6 → 0.4초.
- 기록된 지난 발동 11건의 가로 정도는 0.22~0.84였다(0.7 이상은 2건). 지금까지는 비스듬하거나 세운 손에서도 발동하고 있었다.

## 4. 창 닫기 (Alt+F4), 2단계
- **락 사인**(검지·새끼 펴기, 중지·약지 접기)을 0.5초 유지하면 질문, 같은 모양을 0.5초 더 유지하면 Alt+F4. 풀면 취소, 4초 후 만료. 한 번 닫은 뒤에는 손을 풀어야 다시 센다.
- 모션 모드 안에서 손을 편 채 아래로 쓸어도 같은 2단계. 맨 앞 창이 이 앱·바탕화면·작업표시줄이면 보내지 않고 안내.
- 닫기 요청의 결과(보냄/거부, 앞 창 정보)를 기록과 배지에 남긴다.
- 한계: 실제 창이 닫히는 것은 실물 확인 전이다. 락 사인은 로그에 한 번도 없던 모양이라 임계값은 기하 기준의 시작값이다.

## 5. 마우스 제어 켜기/끄기 (V 사인)
- 검지·중지만 펴고 약지·새끼 접은 V 사인을 1초 유지하면 제어가 켜지고 꺼진다(Space와 동일). 꺼진 동안에도 감시한다. 1초 유지 오탐은 오늘 로그 2만 8천 프레임에서 0번(V 모양 프레임 29개).
- 한계: 실물 확인 전.

## 6. 클릭·드래그·커서 이동
- 더블클릭: 빠른 탭에서 손가락이 0.03만 벌어지고 두 번째 탭이 1~3프레임이라 놓쳤다. 클릭 직후 0.6초 안의 탭은 확인 시간 0, 접촉 후 0.35초 안의 작은 후퇴(0.012)를 뗌으로 본다. 클릭 진입 0.052 → 0.04, 풀림 여유 0.02 → 0.01.
- 드래그 끊김: 접촉이 0.3초 넘게 이어지면 0.06까지 벌어져도 유지(`click_keep_limit`). 중지·약지·새끼 핀치가 끝난 뒤 0.2초는 옆 손가락의 새 핀치 금지.
- 그림판: 핀치하고 손이 0.03 움직이면 1초를 기다리지 않고 바로 드래그(`drag_on_move`). 드래그 중 이동 배율은 손 속도에 따라 2.5배(느림)~15배(빠름). 기록: 드래그 시작이 0.16~0.6초에 일어남을 확인, 느린 구간 배율이 0.4~0.5였던 것을 2.5배 하한으로 보정.
- 커서가 궤적 없이 튐: 주먹 30배에서 한 프레임에 500~1,080px 이동(손은 4~85px). 한 프레임 이동 상한 화면 너비의 12%, 넘친 만큼은 다음 프레임에 이월(최대 2×한도).
- 지연 감소: 손떨림 필터 지연 약 37 → 19ms(`tremor_min_cutoff` 2.0, `tremor_beta` 30), 커서 보간을 프레임 간격의 절반으로. 카메라 30fps 지연은 그대로.
- 주먹 이동 배율 25 → 30배.

## 검증
- `uv run --locked pytest -q`: 328개 통과(1개 건너뜀). 합성 손 모양 시험과 로그 재생. 실제 화면 확인은 대부분 사용자 사용 중 로그로 한 것뿐이다.
