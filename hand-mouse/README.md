# Hand-Mouse: MediaPipe 기반 실시간 핸드 트래킹 가상 마우스

**Hand-Mouse**는 Google의 최신 **MediaPipe Hand Landmarker (Tasks Vision API)**를 활용하여 웹캠이나 스마트폰 카메라 영상 속 21개 3D 손 랜드마크를 실시간 추적하고, 자연스러운 손가락 제스처로 PC 마우스(커서 이동, 클릭, 드래그)를 제어하는 오픈소스 가상 마우스 프로젝트입니다.

---

## 📌 주요 특징

- **정밀한 21개 손 랜드마크 실시간 추적**: MediaPipe Tasks Vision 모델을 통한 안정적인 손 인식.
- **안정적인 커서 이동 (Hysteresis & EMA Smoothing)**: 
  - 핀치가 없을 때 손목→손바닥 기준점으로 커서가 이동하고, 핀치(클릭) 순간에는 커서가 고정되어 클릭 중 마우스 튐 방지.
  - 지수 이동 평균(EMA) 스무딩과 이력현상(Hysteresis) 필터로 진입/해제 경계를 안정화.
- **유연한 카메라 입력 지원**: 일반 PC 웹캠 및 스마트폰 카메라(IP Webcam Wi-Fi 스트리밍, DroidCam/Iriun 가상 웹캠) 완벽 지원.
- **다양한 제스처 동작**: 좌클릭, 우클릭, 드래그 홀드, 드래그 토글 지원.
- **런타임 핫 리로드 (Hot-reload)**: `config/gestures.json` 수정 후 앱을 재시작하지 않고 `R` 키로 즉시 반영.

## 🚀 시작하기

### 1. 환경 설정 및 실행

본 프로젝트는 `uv` 패키지 관리자를 사용합니다.

MANUX Qt Quick 화면을 시험하려면 `uv run --locked --extra qt python main.py --ui qt --source 0`을 실행하세요. Tkinter 화면은 `--ui tk`로 선택할 수 있습니다. 두 화면 모두 시작할 때 OS 입력은 일시정지되어 있습니다. `--ui`를 주지 않으면 카메라 창·트레이 아이콘 모드(추론 스레드 분리)로 실행됩니다. `--ui tk|qt` 화면은 아직 트레이·`--headless`·상태 오버레이·UI 조준 보조를 쓰지 않습니다.

Qt 화면의 검지 포인터 모드에는 클릭 방식이 두 가지 있습니다. 왼쪽 패널의 **클릭 · …** 버튼으로 바꾸며, 바꾸면 제어가 일시정지됩니다.

- **엄지+중지/약지** (기존): 엄지+중지 좌클릭, 엄지+약지 우클릭. ☝️에서 ✋로 손을 펴야 합니다.
- **엄지 방아쇠 (A안, 시험용)**: ☝️를 유지한 채 엄지로 검지 옆(관절 #5~#6)을 누릅니다. 짧게 눌렀다 떼면 좌클릭, 누른 채 가만히 있으면 우클릭, 누른 채 움직이면 드래그입니다. 엄지가 다가오면 커서가 고정되고, 누르기 시작하기 약 0.1초 전 위치에서 클릭합니다. [설계 결정 노트](../docs/design/decision-pointer-click.md)의 선택지 A이며 실제 손으로 측정하지 않았습니다.

방아쇠 기준값은 `config/gestures.json`에 아래 키를 넣어 바꿀 수 있습니다(단위: 손바닥 폭 대비 거리). 상세 정보를 열면 `방아쇠 0.42`처럼 현재 값이 보이니, 누를 때와 뗄 때의 값을 보고 맞추세요.

| 키 | 기본값 | 뜻 |
| --- | --- | --- |
| `trigger_press_ratio` | 0.28 | 이 값 이하이면 누름 |
| `trigger_release_ratio` | 0.40 | 이 값 이상이면 뗌 |
| `trigger_approach_ratio` | 0.50 | 이 값 이하이면 커서 고정 |
| `trigger_long_press` | 0.55 | 이 시간(초) 가만히 누르면 우클릭 |
| `trigger_drag_move` | 0.35 | 누른 채 검지 끝이 이만큼(손바닥 폭 대비) 움직이면 드래그 |
| `trigger_rewind` | 0.10 | 클릭 위치를 되돌리는 시간(초) |

**트래킹만 시험하기 (클릭 끔):** 클릭 방식 버튼을 한 번 더 누르면 **클릭 · 끔 (트래킹만)** 이 됩니다. 클릭을 전혀 판정하지 않고, 손이 보이면 손 모양과 관계없이 커서가 따라갑니다. **기준점** 버튼으로 커서가 따라갈 점을 **검지 끝**과 **손바닥 중심**(Dan 방식) 중에서 고릅니다.

**트래킹 측정:** 왼쪽 패널의 **트래킹 측정 (클릭 없음)** 을 누르면 주 모니터에 전체 화면 측정 창이 뜹니다. Space로 제어를 시작하고, 표적(크기 40·70·110px 원 12개)에 커서를 올려 0.5초 멈추면 다음 표적으로 넘어갑니다. 측정 중에는 클릭하지 않습니다. 표적 하나에 12초가 지나면 실패로 넘어갑니다. Esc로 그만둡니다. 끝나면 결과가 화면에 나오고 `hand-mouse/logs/tracking-날짜-시각.csv`에 저장됩니다(저장소에는 올라가지 않음).

| 기록 | 뜻 |
| --- | --- |
| 도달 / 도달 시간 | 표적이 나타난 뒤 원 안에 0.5초 머물 때까지(머무는 0.5초 제외) |
| 경로 효율 | 직선 거리 ÷ 실제로 움직인 거리. 1이면 곧게 갔음 |
| 멈춤 떨림 | 표적 위에서 머무는 시간의 뒷부분 절반 동안 커서 흔들림(RMS px) |
| 끊김 | 손을 놓친 횟수와 시간 |
| fps / 추론 ms | 측정 중 평균 |

CSV 위쪽 `#` 줄에는 기준점·감도·방향 보정 여부·모니터 크기 같은 설정과 요약이, 아래에는 표적별 기록이 있습니다. 설정을 바꿔 가며 같은 측정을 반복해 비교하세요. 같은 사람의 연속 측정은 독립 시도가 아니므로 사람·조명·카메라 위치도 함께 적어 두세요.

**이동 유지(두 클릭 방식 공통):** 검지 끝이 움직이기 시작하면 멈출 때까지 "포인터 이동"으로 고정하고, 그동안에는 클릭을 판정하지 않습니다. 검지가 0.75초 동안 멈춰 있어야 클릭을 받습니다. 빠르게 움직일 때 ☝️ 판정이 한두 프레임 빠지거나 손이 잠깐 사라져도 이동이 끊기지 않습니다. 멈춘 순간 엄지가 이미 손가락에 닿아 있으면(☝️에서 접힌 중지·약지 끝이 엄지 옆에 있는 경우) 클릭으로 보지 않고, **엄지를 한 번 뗀 뒤 다시 대야** 클릭합니다. 상세 정보에 `이동 0.12 유지`처럼 현재 속도와 유지 여부, 필요하면 `클릭 대기: 엄지를 떼세요`가 보입니다.

| 키 | 기본값 | 뜻 |
| --- | --- | --- |
| `pointer_move_latch` | 0.75 | 이 시간(초) 동안 멈춰 있어야 클릭을 받음 |
| `pointer_move_speed` | 0.20 | 이 속도(프레임 폭/초) 이상이면 이동 유지 시작 |
| `pointer_still_speed` | 0.08 | 이 속도 미만이면 멈춘 것으로 봄 |

**여러 모니터:** 커서는 Windows에 연결된 모든 모니터로 넘어갈 수 있습니다(왼쪽·위쪽 모니터의 음수 좌표 포함, 모니터 사이 빈 영역에는 들어가지 않음). 이동 속도는 주 모니터 폭 기준이라 모니터를 늘려도 빨라지지 않습니다. 절대 좌표 모드(`M`)는 모니터 하나에만 대응하며, **`N`** 키로 다음 모니터로 커서를 옮기고 절대 좌표 대상도 바꿉니다. 모니터별 배율(DPI)이 다른 구성은 실물로 확인하지 않았습니다.


```bash
# 1. USB 웹캠으로 실행 (SNAP U2 등 기본 0번 카메라)
uv run python main.py --source 0

# 2. 무설치 스마트폰 웹브라우저 카메라로 실행 (별도 앱 설치 불필요! 적극 추천)
uv run python main.py --phone-web

# 3. 스마트폰 IP 카메라(IP Webcam 앱 등)로 실행
uv run python main.py --source 192.168.0.15:8080

# 4. 절대 좌표 모드로 실행 (기본은 상대 좌표+가속)
uv run python main.py --mode absolute

# 5. 모의 실행(dry-run: 실제 마우스 클릭/이동 없이 화면에만 표시)
uv run python main.py --dry-run
```

### 2. 주요 실행 옵션

| 옵션 | 설명 | 기본값 |
| :--- | :--- | :--- |
| `--source` | 카메라 인덱스 (`0`, `1`) 또는 `phone`(웹브라우저 모드), 스마트폰 IP/URL (`192.168.x.x:8080`, `rtsp://...`) | `0` |
| `--phone-web` | **무설치 스마트폰 웹브라우저 카메라 모드** 즉시 실행 (`--source phone`과 동일) | `False` |
| `--phone-port` | 스마트폰 웹브라우저 연결용 로컬 HTTPS/WSS 서버 포트 | `8443` |
| `--mode` | 핀치 없을 때 이동 방식 (`relative`: 트랙패드식 상대 이동+가속, `absolute`: 화면 절대 영역 매핑) | `config` 파일 기준 (`relative`) |
| `--config` | 커스텀 제스처 설정 파일 경로 | `config/gestures.json` |
| `--dry-run` | 실제 OS 마우스 이벤트를 발생시키지 않고 시각화만 수행 | `False` |
| `--no-mirror`| 카메라 화면 좌우 반전(거울 모드) 비활성화 | `False` (기본 거울 모드) |

### 관리자 권한 프로그램에서 쓰기 (예: CodeVisionAVR)

Windows는 보안상 **일반 권한 프로그램이 관리자 권한으로 실행 중인 프로그램에 마우스 클릭·휠·키보드 입력을 보내는 것을 막습니다(UIPI)**.
그래서 CodeVisionAVR, 작업 관리자처럼 관리자 권한으로 실행된 창 위에서는 hand-mouse가 동작하지 않습니다.
이럴 때는 **`run_admin.bat`** 을 더블클릭하세요. Windows 권한 확인 창이 한 번 뜨고, hand-mouse가 관리자 권한으로 실행되어 일반·관리자 프로그램 모두에서 동작합니다. **cmd 창 없이** `--headless`(트레이 모드)로 시작하며, 시작 메시지·오류는 `logs/app_latest.log`에 저장됩니다(처음 한 번은 Python 환경 준비 과정이 보입니다)
(옵션도 그대로 전달: `run_admin.bat --phone-web`).

### 버튼 근처 자동 감속 (에임 어시스트)

작은 닫기(X) 버튼·체크박스·링크 같은 **클릭 대상 근처에서 커서가 서서히 느려집니다**(Windows UI Automation 사용). 커서를 끌어당기거나 옮기지는 않고 속도만 줄이며, 주먹(빠른 이동) 중에는 적용되지 않습니다.
설정창 `커서 이동` 탭에서 켜고 끄기, 감속 시작 거리(`ui_magnet_radius`, 기본 28px), 대상 위 속도 비율(`ui_magnet_min_factor`, 기본 0.7)을 조절할 수 있습니다. 크기 200px을 넘는 큰 요소는 대상에서 제외합니다(`ui_magnet_max_size`).
Chrome·Electron 앱은 접근성이 꺼져 있으면 버튼이 잡히지 않을 수 있고(그 경우 평소처럼 동작), 관리자 권한 창은 `run_admin.bat`으로 실행했을 때만 인식됩니다.

### 트레이 모드 / 상태 오버레이 (`--headless`)

- `python main.py --headless` : 카메라 창 없이 **시스템 트레이 아이콘**으로 백그라운드 동작합니다. 트레이 메뉴에서 일시정지·카메라 창(HUD) 열기/닫기·상태 오버레이·설정·종료를 고를 수 있습니다. 카메라 창을 닫으면(X) 트레이로 숨고, 트레이가 없으면 종료됩니다.
- 화면 구석의 **반투명 클릭-스루 상태 위젯**(트래킹 중 / 일시정지 / 드래그 / 스크롤 / 현재 클릭 동작)은 `--headless`에서 기본으로 켜지고, 카메라 창과 같이 쓰려면 `--overlay`, 위치는 `--overlay-corner top-left|top-right|bottom-left|bottom-right`, 끄려면 `--no-overlay`. 트레이 아이콘만 끄려면 `--no-tray`.
- 추론(카메라→MediaPipe→제스처→마우스)은 별도 스레드에서 돌고 카메라 창 그리기는 메인 스레드가 맡습니다. 그래서 창 렌더링이 느려도 커서 반응에는 영향이 없고, 카메라 창을 숨기면 그리기·`imshow` 비용이 0이 됩니다.

## 📱 스마트폰 카메라 연동 방법

별도의 고가 웹캠 없이도 스마트폰 카메라를 고화질 마우스 입력 장치로 손쉽게 활용할 수 있습니다.

### 방법 1: 무설치 스마트폰 웹브라우저 카메라 모드 (`--phone-web` / 실행 중 `P` 키, 적극 추천!)

**스마트폰에 어떠한 앱도 설치할 필요가 없습니다.** iOS Safari 또는 Android Chrome만 있으면 즉시 작동합니다.

1. **PC에서 실행**:
   ```bash
   uv run python main.py --phone-web
   ```
   *(이미 USB 웹캠 모드로 실행 중인 경우에도 카메라 창에서 **`P` 키**를 누르면 즉시 웹브라우저 카메라 대기 모드로 전환됩니다.)*
2. **QR 코드 스캔 또는 HTTPS 주소 접속**:
   - PC 화면에 scannable QR 코드와 주소(예: `https://10.10.21.17:8443`)가 표시됩니다.
   - 스마트폰 기본 카메라 앱으로 QR 코드를 비추거나 모바일 브라우저 주소창에 직접 입력합니다.
3. **자체 서명 인증서 경고 허용**:
   - PC 로컬 자체 서명 인증서이므로 브라우저에 "안전하지 않음 / 연결이 비공개로 설정되어 있지 않습니다" 경고가 나타납니다.
   - **[고급] → [안전하지 않음으로 이동] / [계속 방문]**을 터치합니다.
4. **카메라 권한 허용 및 실시간 스트리밍**:
   - 브라우저의 카메라 권한 요청을 [허용]하면 스마트폰 화면에 카메라 프리뷰가 표시되고, 즉시 PC로 실시간 영상이 전송되어 핸드 트래킹이 시작됩니다.
   - 모바일 웹 화면에서 전면/후면 카메라 전환, 해상도 및 FPS 조절도 가능합니다.

> 💡 **네트워크 연결 팁 (네트워크 대역이 다를 때)**:
> - PC가 유선랜(`10.10.21.x`)에 물려있고 스마트폰이 별도 공유기 Wi-Fi(`192.168.0.x`)에 연결되어 있으면 서로 직접 접속이 안 될 수 있습니다.
> - **해결책 1 (가장 간편)**: 스마트폰을 USB 케이블로 PC에 연결한 뒤, 스마트폰 **[설정] → [개인용 핫스팟 / 테더링] → [USB 테더링]**을 켜면 PC와 스마트폰이 직접 같은 로컬 네트워크로 연결되어 즉시 접속됩니다!
> - **해결책 2**: PC와 스마트폰을 동일한 Wi-Fi 공유기 네트워크에 연결합니다.

### 방법 2: IP Webcam 앱 (Wi-Fi 무선 스트리밍)
1. 스마트폰(Android)에 **IP Webcam** 앱을 설치합니다.
2. 앱 하단의 **[Start server]**를 터치합니다.
3. 화면 하단에 표시되는 IP 주소와 포트(예: `192.168.0.15:8080`)를 확인합니다.
4. PC에서 아래와 같이 실행합니다 (자동으로 `http://.../video` 스트림으로 변환됩니다):
   ```bash
   uv run python main.py --source 192.168.0.15:8080
   ```

### 방법 3: DroidCam / Iriun Webcam (가상 웹캠)
1. 스마트폰과 PC에 각각 **DroidCam** 또는 **Iriun 4K Webcam**을 설치하고 연동합니다.
2. PC에 가상 웹캠 장치(보통 장치 번호 `1` 또는 `2`)로 인식됩니다.
3. 가상 웹캠 인덱스를 지정하여 실행합니다:
   ```bash
   uv run python main.py --source 1
   ```
   *(실행 중에도 카메라 창에서 `C` 키를 누르면 로컬 웹캠 인덱스를 순환 전환할 수 있습니다.)*

## ✋ 기본 손동작 (Default Gestures)

| 손가락 제스처 | 동작 (Action) | 설명 |
| :--- | :--- | :--- |
| **핀치 없음 (아무 손모양)** | **세부 커서 이동** (`move_cursor`) | 손목(#0)→손바닥(중지 뿌리 #9) 기준점을 따라 트랙패드처럼 상대 이동합니다. 천천히 움직이면 정밀(배율 0.35), 빠르게 움직이면 크게(최대 1.2) 움직이는 포인터 가속이 적용됩니다. 던진 뒤·클릭 뒤·손이 다시 들어와도 커서가 튀지 않습니다. 손가락이 엄지에 가까워지면 커서가 멈춰 클릭 위치가 고정됩니다. (`M` 키로 절대좌표 전환 가능) |
| **주먹 쥐기** | **빠른 이동** (`fist`, DPI x20) | 핀치 없음 이동과 똑같이 움직이되 DPI만 `fist_dpi_multiplier`배(기본 20배)로 빨라집니다. 주먹을 쥐었다 펴도 커서가 튀지 않으며, 주먹 상태에서는 엄지가 손가락에 닿아도 클릭/핀치로 인식하지 않습니다. 반대로 엄지+검지 핀치(Record) 중에는 손가락이 말려도 주먹으로 바뀌지 않습니다. 주먹과 핀치는 **검지가 손바닥 안으로 말려 들어갔는지**로 구분합니다(말려 있으면 주먹, 끝이 뿌리보다 밖에 있으면 핀치). 절대좌표·상대좌표 모드 모두 적용. |
| **엄지 + 검지 핀치 (기본)** | **페이지 잡고 스크롤** (`scroll_grab`) | 엄지와 검지를 붙이면 커서 아래 페이지를 잡은 상태가 되고, 붙인 채 손을 움직이면 **터치스크린처럼 페이지가 손을 따라** 스크롤됩니다(손을 내리면 위쪽 내용이 내려옴, 좌우도 가능). 멈춘 뒤 떼면 바로 멈추고, **움직이던 중에 떼면 관성으로 계속 미끄러지다 서서히 멈춥니다**(다시 잡으면 즉시 정지). 작은 떨림은 무시하며 브라우저·문서·파일 목록 등에서 동작합니다. 속도·방향은 설정 창 `엄지·검지` 탭에서 조절. |
| **엄지 + 검지 핀치 (맞닿음)** | **Record & Fling: 그려서 던지기** (`grab`, **기본 꺼짐**) | 설정 창(`O`) 던지기 탭에서 **"엄지·검지 Record & Fling 사용"**을 켜야 동작합니다. 꺼져 있으면 엄지+검지가 닿아도 아무 동작 없이 평소처럼 커서가 움직입니다.  핀치한 채 손을 움직이면 커서는 그대로 있고 **엄지·검지 핀치 포인트의 경로가 기록**됩니다(카메라 화면에 파란 선으로 표시). 핀치를 **떼는 순간** 커서가 기록된 경로를 **그대로 따라 그리며** 이동합니다. 경로의 각 구간은 그린 속도에 따라 확대되어, 천천히 그린 부분은 정밀하게(1배), 빠르게 휙 그은 부분은 크게(최대 4배) 날아갑니다. 커서는 순간이동하지 않고 0.15~0.45초 동안 부드럽게 움직여 이동 선이 눈에 보입니다. 재생 중 다시 핀치하면 그 자리에서 멈춥니다. |
| **엄지 + 중지 핀치** | **좌클릭 / 더블클릭** (`left_click`) | 엄지와 중지 끝을 가볍게 맞닿으면 왼쪽 버튼이 1회 클릭됩니다. **빠르게 두 번 붙였다 떼면 더블클릭**, **0.6초 이상 길게 붙이고 있으면 드래그**(왼쪽 버튼을 누른 채 손을 따라 이동 → 떼면 놓기, 파일 끌기용) — 손가락을 뗐다 다시 붙인 핀치는 쿨다운 없이 바로 클릭되고, 클릭 후 `double_click_window`(0.45초) 동안 커서가 고정되어 두 클릭이 같은 자리에 찍힙니다. 붙인 채로 있어도 반복 클릭되지 않습니다(마우스 버튼처럼 핀치 1번 = 클릭 1번). 핀치를 유지하는 동안 커서는 고정되고 화면 상단에 `PINCH HELD`가 표시됩니다. |
| **엄지 + 약지 핀치** | **우클릭** (`right_click`) | 엄지와 약지 끝을 맞닿으면 마우스 오른쪽 버튼이 1회 클릭됩니다 (컨텍스트 메뉴 호출). |
| **엄지 + 검지 + 중지 동시 핀치** | **드래그 홀드** (`drag_hold`) | 세 손가락을 모아 쥐면 마우스 왼쪽 버튼을 누른 상태(Down)로 유지하며 드래그합니다. 떼면 놓기(Drop)됩니다. |
| **엄지만 접고 네 손가락 펴기** | **바탕화면 보기** (`show_desktop`, Win+D) | 엄지를 손바닥 쪽(약지·새끼 뿌리 근처)으로 접고 검지·중지·약지·새끼를 모두 편 자세를 **0.4초 유지**하면 모든 창을 내리고 바탕화면을 보여줍니다(한 번 더 하면 복원). 자세를 유지하는 동안은 한 번만 실행되고, 다시 하려면 손 모양을 풀었다 다시 만드세요. 핀치 동작들은 모두 손가락 하나를 엄지 쪽으로 굽히므로 이 자세와 겹치지 않습니다. 손바닥이 카메라를 향할 때만 인식하며, 카메라 창 상단 `Tuck:` 값이 기준 이하가 되면 엄지 접힘으로 판정합니다. 1.5초 쿨다운. |
| **엄지 + 소지(새끼) 핀치** | **창 전환 화면** (`task_switcher`) | Windows 창 전환 화면(Alt+Tab)을 열어 둡니다. **커서는 평소처럼 움직이므로**(손 펴기 = 미세, 주먹 = 빠르게 · 창 전환 중에는 주먹을 쥐다 엄지·검지가 닿아도 이동으로 처리) 원하는 창 썸네일 위로 가져간 뒤 **엄지+중지 핀치**로 클릭하면 그 창으로 전환됩니다. **엄지+새끼** 다시 = 현재 강조된 창으로 전환, **엄지+약지** = 취소. 손이 1초 넘게 사라지거나 15초가 지나면 자동 확정해 Alt 키가 눌린 채 남지 않습니다. 방향키로 고르고 싶으면 `"switcher_navigation": "arrows"`(손 움직임 = 방향키, 주먹 = 취소). |

## ⌨️ 카메라 창 단축키 안내

카메라 화면 창이 활성화된 상태에서 아래 키를 입력하여 실시간으로 기능을 제어할 수 있습니다.

- **`O`** (또는 `0`, 다른 창에서도 **`F2`**) : **설정 창 열기/닫기** — 한글 입력 상태여도 동작. 탭(던지기 / 핀치·클릭 / 커서 이동 / 창 전환)별로 슬라이더와 숫자 입력칸, 설명이 있고 [저장] / [저장된 값으로 되돌리기] / [기본값] 버튼 제공 — 슬라이더로 Fling 거리·가속, 핀치/클릭 민감도, 이동 민감도·스무딩, 주먹 배율 등을 실시간 조절 (설정 창에서도 `S` 저장, `R` 되돌리기)
- **`Space`** : 마우스 제어 일시정지(Pause) / 재개(Resume) 토글 (화면 조작 중 잠시 멈출 때 유용)
- **`M`** : 핀치 없을 때 이동 모드 전환 (`RELATIVE` 트랙패드 상대 좌표(기본) ↔ `ABSOLUTE` 절대 좌표)
- **`+` / `-`** : 핀치 인식 감도 미세 조정 (`+`: 더 민감하게, `-`: 더 엄격하게)
- **`C`** : 로컬 웹캠 장치 인덱스 순환 전환 (`0` → `1` → `2` → `0`)
- **`P`** : 무설치 스마트폰 웹브라우저 카메라 모드 (`phone-web`)로 전환 (QR 코드 안내 화면)
- **`R`** : `config/gestures.json` 설정 파일 실시간 재로드 (**핫 리로드**)
- **`[` / `]`** : Record & Fling 확대 배율(던지는 거리) 조절 (`]`: 1.2배 멀리, `[`: 1.2배 짧게, 화면 상단 `Fling:` 값으로 확인, `S`로 저장)
- **`S`** : 현재 런타임에서 변경된 감도 및 설정을 `config/gestures.json`에 영구 저장
- **`Q` / `ESC`** : 프로그램 안전 종료 및 리소스 해제

## ⚙️ 설정 커스터마이징 (`config/gestures.json`)

`config/gestures.json` 파일에서 각 제스처의 동작 매핑 및 인식 파라미터를 원하는 대로 수정할 수 있습니다.

```json
{
  "record_fling_enabled": false,  // 엄지+검지 Record & Fling 사용 여부 (기본 꺼짐, 설정 창에서 켜기)
  "grab_scroll_enabled": true,    // 엄지+검지 핀치로 페이지 잡고 스크롤 (Record & Fling이 켜져 있으면 그쪽이 우선)
  "scroll_gain": 24000.0,         // 손을 프레임 폭만큼 움직였을 때 휠 양 (120 = 휠 한 칸)
  "scroll_deadzone": 0.01,        // 잡은 뒤 이만큼 움직여야 스크롤 시작 (떨림 무시)
  "scroll_invert": false,         // true = 휠 방향 (손을 내리면 페이지가 위로)
  "scroll_inertia": true,         // 스크롤 관성: 핀치를 '떼었을 때만' 적용, 움직이던 중에 떼면 계속 미끄러지다 서서히 멈춤 (다시 핀치하면 즉시 멈춤)
  "scroll_release_margin": 0.02,  // 스크롤 중에는 손가락이 이만큼 더 벌어져야 '뗌'으로 판정 (빠른 손동작 떨림 대비)
  "scroll_release_grace": 0.25,   // 스크롤 중에는 이 시간(초) 이상 떨어져 있어야 '뗌'으로 판정
  "hand_lost_reset": 0.3,         // 손이 잠깐(이 시간 이하) 인식에서 사라져도 잡기/드래그 상태 유지
  "scroll_inertia_time": 0.4,     // 관성 감속 시간 상수(초), 클수록 오래 미끄러짐
  "scroll_inertia_min_speed": 600.0, // 이 속도(휠 단위/초) 이상으로 움직이던 중에 떼야 관성 시작
  "pinch_threshold": 0.055,       // 핀치 진입 거리 임계값 (작을수록 손가락을 더 가깝게 붙여야 함)
  "release_threshold": 0.075,     // 핀치 해제 거리 임계값 (이력현상 방지)
  "pinch_release_grace": 0.15,    // 카메라 각도로 손끝이 가려져 판정이 잠깐 끊겨도 이 시간(초)까지는 핀치 유지
  "click_threshold": 0.052,       // 클릭 판정 거리 임계값
  "ring_click_threshold": 0.044,  // 엄지+약지(우클릭) 판정 거리 (작을수록 확실히 닿아야 인식)
  "smoothing": 0.35,              // 커서 스무딩 계수 (0에 가까울수록 부드러움, 1에 가까울수록 즉각 반응)
  "cursor_interpolation": true,   // 커서 보간: 카메라는 30fps지만 커서는 144Hz로 부드럽게 이동 (클릭 직전엔 정확한 위치로 맞춤)
  "tremor_filter": true,          // 손떨림 보정 (One Euro 필터 + 미세 떨림 무시) 사용
  "tremor_min_cutoff": 1.5,       // 멈춰 있을 때 보정 강도 (낮을수록 강함, 켜져 있으면 smoothing 대신 사용)
  "tremor_beta": 8.0,             // 빠르게 움직일 때 보정을 풀어 지연을 줄이는 정도 (클수록 반응 빠름)
  "tremor_deadzone": 0.002,       // 이보다 작은 손 움직임은 무시 (조준 중 커서 고정)
  "active_margin": 0.30,          // 절대 좌표 모드 시 유효 화면 여백 비율 (클수록 손을 조금만 움직여도 커서가 크게 이동)
  "movement_mode": "relative",    // 핀치 없을 때 이동 방식: "relative"(기본, 세부 조정) 또는 "absolute"
  "relative_gain_min": 0.35,      // 천천히 움직일 때 배율 (정밀 미세조정)
  "relative_gain_max": 1.2,       // 빠르게 움직일 때 배율
  "relative_accel_speed_low": 0.1,  // 이 속도 이하 = 최소 배율 (프레임 폭/초)
  "relative_accel_speed_high": 0.8, // 이 속도 이상 = 최대 배율
  "cursor_anchor_ratio": 0.5,     // 커서 기준점 위치 (0.0 = 손목, 1.0 = 중지 뿌리, 0.5 = 손바닥 중앙)
  "fist_confirm_time": 0.12,      // 주먹 모양이 이 시간(초) 유지돼야 주먹 판정 (손가락 굽힘은 깊이(z)까지 포함해 3D로 측정)
  "fist_dpi_multiplier": 20.0,     // 주먹 쥐었을 때 이동 배율 (핀치 없음 이동 대비)
  "pinky_tuck_ratio": 0.8,        // 새끼가 이보다 깊게 접혀 있으면 엄지가 닿아도 창 전환 아님 (브이 자세/주먹)
  "gesture_exclusive_time": 1.0,  // 바탕화면(Win+D)과 창 전환은 한쪽 실행/진행 중 이 시간(초) 동안 다른 쪽 무시
  "switcher_fist_multiplier": 15.0, // 창 전환 화면에서 주먹 이동 배율 (평소 주먹 배율보다 약간 낮게)
```
